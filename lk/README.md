# Кабинет Начерта — nachert1830.ru/lk/

Кабинет в разработке (`noindex`, без ссылок с сайта). Сейчас работают: группа и сроки сдач (база занятий ниже)
и **сканер чертежей** — центральная кнопка «Скан».

## Экраны и цвета

Тёмная сцена, три ярких акцента — каждый со своим смыслом, остальное — спокойные карточки:

| Цвет | Что | Где |
|---|---|---|
| красно-оранжевый | **«Горит»** — ближайшее несданное ДЗ: счётчик дней, сколько времени прошло, «Разбор на сайте», «Сдал»; долги (прошедшие ДЗ без отметки) | Главная, Сдачи |
| электрик-синий | **сканер чертежа**: «Сканировать» / «Из галереи», «Мои чертежи» | Главная, центральная кнопка меню |
| фиолетовый | **подготовка к РК**: ближайший РК по каждому предмету, 4 шага со ссылками на сайт, готовность по отметкам | Главная, вкладка «РК» |

Меню: Главная · Сдачи · **Скан** · РК · Профиль. Телефон — плавающее меню снизу, сканер в центре.
Компьютер (от 880 px) — боковая панель слева, сверху яркая кнопка «Сканер чертежа», окно группы по центру;
от 1180 px на главной «Горит» и сканер рядом, РК и сроки — в две колонки, на вкладке «РК» предметы рядом.

- **Сдачи** — все ДЗ, РК и модули по неделям; галочка — «сдал» (`localStorage.lk_done`), долги сверху,
  «Всё прошедшее — сдано» одной кнопкой, фильтр Все · ДЗ · РК, счётчик на вкладке — долги и сроки на 7 дней.
- **РК** — шаги подготовки (`localStorage.lk_prep`): начерт — шпаргалка, вопросы и билет, темы, пробный РК;
  ИКГ — виды и разрезы, защита точек, теория ЕСКД, рабочая тетрадь.
- План семестра — массив `TABLE` в `index.html` (предмет, вид, номер, неделя срока); день — по паре группы.

## Сканер чертежей → «Мои чертежи» → доводка → 3D

Путь студента:

1. **Скан** (центральная кнопка или баннер «Оцифруй лист по фото» на главной) → «Сканировать» (камера) или
   «Из галереи». Нужен код доступа к сканеру («Настройки сканера»); без кода — «Попробовать на примере».
2. Сканер (`scan/pipeline.js`, общий с бета-страницей `scan/`) находит чертежи на листе, оцифровывает каждый
   (облачная функция `server/scan/` → модель), уточняет линии по карандашу и привязывается к условию варианта ДЗ —
   копия получается в мм листа от начала O.
   Модели (облачная функция `server/scan/`): раскладка — Claude Haiku 5.5; каждый чертёж оцифровывают **две модели
   независимо — Claude Opus 5.5 и Claude Sonnet 5.5** (сбой Opus — тот же кадр Sonnet); ответы сливаются (`scan/merge.js`):
   точки по подписям усредняются, пропущенное одной добавляет другая, а что из добавленного настоящее, решает карандаш на
   фото. Замер (7о): две модели вместе — точки на 20 % точнее (0,46 мм против 0,57), найдено 81 из 83; Opus один — не лучше
   Sonnet. «Настройки сканера» → «Точность»: максимальная (так, ≈ $0,026 за чертёж) · экономная (вторая модель — только
   если копия слабая: не привязалась к варианту, невязка > 0,8 мм, > 10 % линий без карандаша) · быстро (одна). Какая связка точнее — замер `lab/dz/scan-ab.js`
   (Actions «Сканер — какая связка моделей точнее»), итоги — `lab/dz/REPORT.md`, раздел 7о.
3. Лист сохраняется в **«Моих чертежах»** (в этом браузере: копии — `localStorage`, фото — IndexedDB) и открывается:
   - **Копия** — правка: подписи (″ / ′ одним касанием), сдвиг точек, новые точки и отрезки, тип линии,
     подтвердить / убрать сомнительную линию, начало O, фото под копией, отмена;
   - **Доводка** — что поправить, чтобы копия стала верным эпюром: точки без пары, подпись без штриха, разрыв
     линии связи, точка условия не на месте (сверка с таблицей варианта), не подтверждённые линии, рёбра только
     на одной проекции; исправления в одно касание и «Исправить всё». Привязка к варианту вручную, если сканер
     вариант не узнал (копия пересчитывается в точные мм по точкам условия);
   - **3D** — тело по двум проекциям (A = (x, y, z) из A″ и A′) в углу Монжа: плоскости П₁ и П₂, проекции, линии
     связи, видимость рёбер; «Развернуть в эпюр» — П₁ поворачивается вокруг оси x и ложится в П₂; эталон варианта
     (условие + решение `core/dz.js`) и отклонение каждой точки; выгрузка OBJ и PNG.

| Файл | Что это |
|---|---|
| `scan/pipeline.js` | Конвейер оцифровки листа (раскладка → оцифровка → уточнение → привязка; `digest` — один чертёж, `quality` — его качество), общий для кабинета и `scan/` |
| `scan/merge.js` | Слияние двух оцифровок одного чертежа: точки по подписям, отрезки без дублей; добавленное второй моделью без карандаша — вон |
| `drawings/model.js` | Логика (Node и браузер): результат сканера → чертёж в мм, подписи, 3D по парам проекций, рёбра и грани, замечания и исправления, привязка к варианту, SVG и OBJ |
| `drawings/view3d.js` | 3D на canvas без библиотек: вращение, виды, разворот в эпюр, видимость рёбер лучом |
| `drawings/ui.js`, `drawings/ui.css` | Вкладка «Скан», «Мои чертежи», экран чертежа (Копия · Доводка · 3D) |
| `drawings/demo.js` | Пример (ДЗ №3, в.21) в формате сканера, с типичными огрехами фото |

Проверка — `node tests/lk-drawings.js` (входит в `node tests/run.js`).
