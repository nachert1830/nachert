# Кабинет Начерта — nachert1830.ru/lk/

Функции кабинета удалены, страница — заглушка (`noindex`, без ссылок с сайта). Остальное переделываем.

Остаётся только база занятий:

- `data/raw/*.txt` — расписание кафедры РК-1 с 01.09.2026, переписано с фото стенда (по файлу на день недели);
- `data/groups.json` — собирается из них: `node lk/tools/groups.js` (запускать после правки txt);
- формат строки в txt описан в шапке `tools/groups.js`.
