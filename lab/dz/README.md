# lab/dz/: фото листа ДЗ №2–3 → ориентация → рамка → эпюр → чертёж в числах

Лист: А3, книжный, рамка и основная надпись начерчены студентом (ГОСТ 2.301, 2.104 форма 1), карандаш.
Всё работает в Node и (без сборщика) в браузере, без сервера. Фото студентов кладутся только в `lab/private/`.
Эта папка не попадает в git (`lab/.gitignore`).

| Файл | Что делает |
|---|---|
| `sheet.js` | Геометрия листа: страница 297 × 420, рамка 20/5/5/5 мм, штамп 185 × 55 в правом нижнем углу, поле чертежа. |
| `locate.js` | Фото → лист: кандидаты рамки (Хаф по тонким линиям, внутренность рамки, край страницы) × 4 поворота снимка; рамка годится, только если все 4 стороны прочерчены; ориентацию даёт узор штампа (верх 185 мм, вертикали, строки по 5 мм) на месте против того же узора в противоположном углу; уточнение по гребню; ось x (самая длинная горизонталь поля, продлевается с пониженным порогом), ось z/y (длинная вертикаль у правого конца оси x), O — их пересечение. Не уверен — отказ с причиной. |
| `digitize.js` | Лист → чертёж: рамка чертежа по клеткам с линиями (+5 мм), линии — `lab/lines.js` (гребни, Хаф по направлению, тип основная / тонкая / штриховая, σ), координаты в мм от O (u вправо, v вниз — как у сцен сайта). |
| `synth.js` | Синтетический лист: эталонные сцены разборов сайта (`examples.json`), начерченные «рукой» (дрожь, неточная рамка), съёмка телефоном (перспектива, свет, тень, шум) и поворот снимка на 0/90/180/270°. |

| `calib.js` | Калибровка по условию варианта: подгонка фигуры условия к линиям листа, гипотезы «точка нанесена с ошибкой», какой вариант начерчен. |

| `explain2.js` | Разбор по шагам ДЗ №2а: на каком шаге ошибка. Каждый шаг меряется по линиям листа и сверяется со своим же предыдущим шагом студента. |
| `report2.js` | Картинка разбора (SVG, мм чертежа): линии листа, точки построения студента, верный ответ, шаги ✓/✗/?, увеличенный кусок у S. |

| `eyes.js` | Глаза и мозг: модель со зрением (сервер кабинета, `server/lib/eyes.js`) даёт подписи точек условия и чертежи листа, примерно; сканер привязывается по ним (аффинное, перепутанные подписи выпадают), уточняет перспективу по измеренным точкам и проверяет каждый чертёж как обычно. | `gridsheet.js` | Лист в клетку → проверка: калибровка, данные как начерчены, эталон для варианта И для начерченной пирамиды, ответы студента — «верно» / «ошибка в данных» / «ошибка в построении». `node lab/dz/gridsheet.js фото.png --dz=3 --n=7 --phi=25`. |
| `explain3d.js`, `report3d.js` | ДЗ №3 г) по шагам начерченного построения (n″, h₁″ → 3′, 4′ → радиус → ψ) и картинка разбора. |
| `gsynth.js`, `test-grid.js` | Синтетический лист в клетку с ошибкой нанесения или шага г) и тест: правда известна для каждой координаты и шага. |

| `test-live.js` | То же на настоящем сайте nachert1830.ru (ссылка входа владельца — `server/tools/login.js`); запускается в Actions: `.github/workflows/scanner-live.yml`, снимки — артефакт `scanner-live`. |
| `series.js`, `test-series.js` | Серия кадров одного листа → один вердикт: кадры голосуют, замер — медиана, σ — по разбросу кадров, утверждение — только если его подтверждают ≥ ⌈2k/3⌉ кадров и никто не против. Тест: один и тот же лист снят 3 раза (другой наклон, свет, блик). |
