# lab/dz/: фото листа ДЗ №2–3 → ориентация → рамка → эпюр → чертёж в числах

Лист: А3, книжный, рамка и основная надпись начерчены студентом (ГОСТ 2.301, 2.104 форма 1), карандаш.
Всё работает в Node и (без сборщика) в браузере, без сервера. Фото студентов кладутся только в `lab/private/`.
Эта папка не попадает в git (`lab/.gitignore`).

| Файл | Что делает |
|---|---|
| `sheet.js` | Геометрия листа: страница 297 × 420, рамка 20/5/5/5 мм, штамп 185 × 55 в правом нижнем углу, поле чертежа. |
| `locate.js` | Фото → лист: кандидаты рамки (Хаф по тонким линиям, внутренность рамки, край страницы) × 4 поворота снимка; рамка годится, только если все 4 стороны прочерчены; ориентацию даёт узор штампа (верх 185 мм, вертикали, строки по 5 мм) на месте против того же узора в противоположном углу; уточнение по гребню; ось x (самая длинная горизонталь поля, продлевается с пониженным порогом), ось z/y (длинная вертикаль у правого конца оси x), O — их пересечение. Не уверен — отказ с причиной. |
| `digitize.js` | Лист → чертёж: рамка чертежа по клеткам с линиями (+5 мм), линии — `lab/lines.js` (гребни, Хаф по направлению, тип основная / тонкая / штриховая, σ), координаты в мм от O (u вправо, v вниз — как у сцен сайта). |
| `synth.js` | Синтетический лист: эталонные сцены разборов сайта (`examples.json`), начерченные «рукой» (дрожь, неточная рамка), съёмка телефоном (перспектива, свет, тень, шум) и поворот снимка на 0/90/180/270°. |
| `fetch-examples.js` | Достаёт итоговые сцены разборов ДЗ 2а–2в и 3 с сайта → `examples.json`. |
| `show.js` | Разбор настоящего фото: печатает найденное и пишет картинки (наложение, выпрямленное поле, чертёж с оцифрованными линиями) и сцену `-сцена.json`. |
| `test-locate.js`, `test-digitize.js` | Замеры на синтетике (ниже). |

## Цифры (каждая — одной командой)

`node lab/dz/test-locate.js --n=12`: найдено 12 из 12, ориентация верна 12 из 12. Рамка — медиана 0,57 мм,
худшая 0,87 мм. Ось z/y найдена 9 из 9, ложных O 0, O — медиана 0,54 мм, худшая 0,65 мм.

`node lab/dz/test-locate.js --n=12 --level=hard` (тень поперёк листа, слабый свет, блики): найдено 6 из 12,
остальные 6 — отказ с причиной. Ориентация верна 6 из 6, ось z/y найдена 4 из 5, ложных O 0, O — худшая 0,45 мм.

`node lab/dz/test-digitize.js --n=8`: оцифровано 7 из 8 (1 отказ: рамка не найдена). Полнота линий — медиана
97 %, худшая 95 %. Точность — медиана 99 %, худшая 98 %. Тип линии верен — медиана 89 %.

Настоящее фото (ДЗ №2а, вариант 8, `node lab/dz/show.js lab/private/dz2a-v8-1.png`): снимок не повёрнут,
4,4 px/мм, штамп 0,83 против 0,03, O = (271,6; 189,7) мм листа, 228 отрезков. Проверено глазами по наложению.

## Чего здесь пока нет и почему

- **Сверки с вариантом.** Нужны таблицы вариантов ДЗ №2 и №3. По ним O (если оси z/y нет) находится по
  проекциям одной заданной точки. Заданные точки служат опорными: по ним уточняется масштаб и перекос
  (самокалибровка). После этого построение студента сравнивается с эталонным построением сайта для того же
  варианта. Студент указывает вариант сам, и приложение просит его подтвердить номер.
- **Масштаб по рамке — с точностью руки.** Рамка начерчена от руки (углы ± до 1,5 мм), поэтому мм «по рамке»
  отличаются от мм бумаги на доли процента. Самокалибровка по заданным точкам варианта это уберёт.
- **Подписи почерком** пока не читаются. Их штрихи попадают в отрезки как короткие линии.
