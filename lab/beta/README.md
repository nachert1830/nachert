# Бета оцифровки листа

Фото листа с чертежом → цифровая копия в миллиметрах (SVG и JSON). Вердикта нет: только «что нарисовано».

## Запуск (нужен Node 20+ и ключ ProxyAPI)
```bash
PROXYAPI_KEY=ваш_ключ node lab/dz/beta-server.js
```
Открыть http://127.0.0.1:8787/ → «Фото листа» → «Оцифровать». Расходы считаются по токенам и ограничены `--limit=3` (доллары).
С телефона в той же сети: `BETA_PASSWORD=пароль PROXYAPI_KEY=… node lab/dz/beta-server.js --host=0.0.0.0` и адрес компьютера в сети;
пароль спросят один раз (без пароля наружу сервер не откроется).

## Что происходит
1. Haiku находит чертежи на листе (кадр ≤ 800 px, ≈ $0,003).
2. Браузер режет лист на чертежи и поворачивает их.
3. Sonnet оцифровывает каждый чертёж: точки с подписями, отрезки, окружности и дуги (≈ $0,01–0,02 за чертёж).
4. Притяжка к карандашу на самом снимке (`lab/dz/refine.js`): линии уточняются, выдуманные убираются, пропущенные и дуги ищутся.
5. Задание и вариант определяются по точкам условия; перспектива снимка учитывается; копия пересчитывается в мм.

Сервер раздаёт только `lab/` и `core/` (без `lab/private`, `lab/photos`, `.git`), фото не сохраняет, ключ в страницу не отдаёт.

## Цвета
Зелёная линия — подтверждена карандашом на снимке; оранжевая пунктиром — модель написала, а карандаша под ней мало (не подтверждено);
синяя — найдена сверх ответа модели; малиновые точки — подписанные точки.

## Что не умеет
ДЗ №1 (нет в ядре сайта), эллипсы и лекальные кривые (кривые пересечения поверхностей), привязка призмы и куба не всегда сходится
(модель не выписывает концы заданной прямой `E`, `F`), разрешение ниже 5 px/мм снижает точность. Подробности и цифры — `lab/dz/PLAN-digit.md`.

## Проверки без расходов
`node lab/dz/test-circles.js`, `node lab/dz/test-digit-refine.js`, `node --test server/test/sheet-modes.test.js`;
`beta-server.js --mock=<папка с mock.json>` отвечает сохранёнными ответами моделей (для проверки страницы).
