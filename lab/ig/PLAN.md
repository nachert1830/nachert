# Чертёжное зрение · первый запуск: ИГ ДЗ №4 «Тело с вырезом K»

Путь: **снимок листа → граф чертежа (мм листа) → 3D (параметры выреза K) → проверка по видам**. Только ДЗ №4.

## Что есть и что берём
- Эталон — сам сайт: модуль IG3/IGS из `index.html` загружается в Node (`lab/ig/ig3node.js`, как `hands/tools/extract-models.js`),
  чистовик варианта `IGS.sheet(...,'clean')` (А3, 1:1) разбирается в граф (`lab/ig/ref.js`). Каждая линия эталона знает своё 3D-ребро
  (`IG3.drawing().lines`: a3/b3, видимость), поэтому «где ошибка» говорится и на листе, и на детали.
- Модели вариантов — `dz/ig/4/models.js`: тело + вырез K (многоугольник на главном виде, протянутый вдоль y).
- Сканер начерта: идея «модель даёт кандидатов, карандаш решает», ICP-привязка по очеркам (`lk/scan/bind4.js`), кэш ответов модели
  по хэшу (`lab/dz/verdict-eval.js`), камера синтетики (`lab/synth.js`). Ветки с bind4/verify4/verdict ещё не в `main` — эта ветка
  начата от `claude/practical-ritchie-iw1b6a` (там они есть).

## Граф чертежа (формат `ig-graph` v1, описан в `GRAPH.md`)
Лист в мм (x вправо, y вниз, А3 420×297). Виды `F` (главный), `T` (сверху / с разрезом А–А), `L` (слева) — рамка, вид изображения
(вид / полуразрез / разрез), привязка к модели (аффинное отображение «мм детали → мм листа») и невязка. Линии — ломаные с типом
ГОСТ 2.303: `main`, `hidden`, `axis`, `thin`, `wavy`, `open` (разомкнутая), уверенность и доказательство карандашом
(доля длины с графитом, ритм штрихов). Штриховка — области. Проекционные связи F↔T (по x), F↔L (по z) с невязкой.

## Конвейер
1. **Рамка листа → гомография.** Модель называет углы рамки, код уточняет каждую сторону по карандашу (МНК по поперечным профилям).
2. **Чтение.** Модель (Claude Sonnet, один запрос на лист) — виды с рамками и линии с типами в px кадра. Имитация модели для
   синтетики — по начерченной правде с погрешностью и ошибками «как у модели» (пропуск, лишняя, перепутанный тип).
3. **Карандаш решает.** Каждая линия притягивается к графиту (поперечные профили, МНК), подтверждается долей длины с графитом;
   тип — по ритму штрихов (сплошная / штриховая / штрихпунктирная) и толщине относительно листа. Нет графита — линия не в графе.
4. **Привязка вида к модели.** Сдвиг (+ масштаб ≈ 1) вида эталона к видам студента: ICP по основным линиям (контур тела не зависит от
   того, где разрез). Невязка — медиана расстояний. Вариант изображения (вид / половина / разрез и где граница) выбирается по совпадению
   из допустимых — проверяется результат, а не выбор композиции.
5. **Граф → 3D.** Параметрически: тело из `models.js`, вершины K подгоняются МНК по линиям выреза на главном виде (стороны K —
   прямые, вершины — пересечения). Интерфейс `reconstruct(graph, prior)` → `{params, tree, resid}`: потом сюда встанет общая
   реконструкция по видам без известного дерева.
6. **Проверка.** По каждому виду: эталон ↔ граф студента (линии main/hidden, 3D-ребро каждой). «Ошибка» — только при доказательстве:
   расхождение ≥ 2 мм, привязка вида с невязкой ≤ 0,7 мм, линия подтверждена карандашом. Иначе «не уверен» с причиной.
   Согласованность видов без эталона: K на главном виде (подогнанный) → его линии на виде сверху и слева (проекционная связь, глубины).

## Метрики (`lab/ig/eval.js`, режимы: имитация модели — без денег; настоящая модель с кэшем, `--replay`)
- линии графа (main/hidden/axis/wavy) против правды в 1 мм: полнота, точность; тип линии верен;
- 3D: ошибка вершин K, мм;
- вердикт: верные виды → «верно», ошибочные → «ошибка» с местом (на виде, ≤ 3 мм от подсаженной), **ложных «ошибка» 0**.
Цели первого запуска — из задачи: 95/95 %, тип 90 %, K ≤ 1 мм, ошибки ≥ 80 %, ложных 0. Настоящие фото — `lab/private/ig4real/`.
