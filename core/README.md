# core/ — ядро проверки (общее для tests/ и сканера lab/)

Каждый файл работает и в Node (`require`), и на странице (глобальные `CERT` / `CORE`), без сборщиков.

| Файл | Что это |
|---|---|
| `exact.js` | Точная арифметика: рациональные числа на BigInt, векторы. |
| `kernels.js` | Два независимых исполнителя: ядро 3D (пространство) и ядро 2D (эпюр: линейка и угольник), проекции. |
| `certify.js` | Сертификат задачи — обязательства O1–O9 (см. tests/README.md, раздел `certified/`). |
| `t46.js`, `t47.js`, `list.js` | Условия и протоколы задач № 46 и № 47, их решатели, подсаженные ошибки сертификата. |
| `model.js` | Модель пространства и проекций в мм листа (с плавающей точкой): A″ = (−x, −z), A′ = (−x, y); восстановление 3D по двум проекциям с невязкой линии связи. |
| `scene.js` | Формат «оцифрованная сцена»: элементы как у сцен сайта (`{t:'pt',at,l}`, `{t:'seg',a,b,k}`, …) в мм + `σ` (погрешность, мм) и `conf` (уверенность 0…1); перевод в единицы сайта, SVG. |
| `cp.js` | Программа построения на листе: действия (∥ оси, линия связи, ⟂, пересечение, перенос циркулем…), её исполнение, чертёж, операции правки. |
| `cp47.js` | № 47 как программа: верные способы (посредник γ фронтально- и горизонтально-проецирующий; треугольник натуральной величины на π₁/π₂ при любом конце) и библиотека ошибок — операции над верной программой. |
| `cp46.js` | № 46 как программа: посредники γ₁ ⊃ DF, γ₂ ⊃ EF → точки 5, 6, отрезок 56; узор видимости (основная / штриховая по сторонам) по 3D; ошибки точек и видимости. |
| `test.js` | `node core/test.js [--browser]` — программа № 47 против сертификата (точно, на 200 случайных вариантах), каждая ошибка даёт неверный ответ, формат сцены и 3D; № 46 — точки против сертификата, узор видимости против аудита сертификата t46. |

Старые адреса `tests/certified/{exact,kernels,certify,list,t46,t47}.js` — переходники на `core/`: тесты и тренажёр
сайта (он подгружает их по требованию) работают как раньше. `node tests/run.js` — «Ошибок нет».

Сканер фото листа, который стоит на этом ядре, — `lab/` (отчёт: `lab/REPORT-scanner.md`).
