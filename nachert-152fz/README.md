# Начерт

Начертательная геометрия по шагам: решённая тетрадь, подготовка к РК, разборы ДЗ и интерактивная 3D-модель с эпюром.

Независимый некоммерческий учебный проект. Не является официальным сайтом МГТУ им. Н.Э. Баумана.
Условия задач, теория и методика — по учебным изданиям МГТУ (список источников — на странице «О проекте»).
Решения, чертежи, пояснения и код подготовлены для этого сайта.

Автор — Андрей Матханов.

Сайт — один файл `index.html`, работает без сборки, установки и регистрации.
Шрифты (Golos Text, Geologica, IBM Plex Mono) лежат в папке `fonts/`, лицензия SIL Open Font License 1.1.
