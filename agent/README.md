# agent/ — «гений + зануда» для задачи № 47

LLM только **предлагает** план построения. Детерминированное ядро **исполняет** его. Сертификат **проверяет**.
Если за N попыток сертификат не пройден, агент отвечает «не решено» и называет причину. Непроверенный ответ
пользователю не выдаётся никогда. Цифры и примеры из логов — в [RESULTS.md](RESULTS.md).

```
условие варианта (текст) ──► генератор (LLM, OpenRouter) ──► план: JSON-программа core/cp.js
                                    ▲                              │
                                    │ текст ошибки                 ▼
                                    │                 исполнитель: agent/plan.js → core/cp.js
                                    │                              │ (формат, имена, типы, вырождения)
                                    │                              ▼
                                    └──────── нет ──── зануда: core/certify.js (O9 O1 O2 O3 O6 O4 O5 O7)
                                                                   │ да
                                                                   ▼
                                                 ответ: K″, K′, |AK| ≈ N мм + сертификат
```

## Запуск

```bash
node agent/eval.js
```

Эта команда воспроизводит таблицу RESULTS.md по логу `agent/logs/eval.jsonl`. Сеть не нужна. Каждый записанный
ответ модели заново проходит исполнитель и сертификат текущего кода. Если что-то разошлось с логом, команда
выведет расхождения и завершится с кодом 1. В конце — контроль зануды на библиотеке ошибок `core/cp47.js`.

```bash
node agent/eval.js --live
```

Новый прогон через OpenRouter: 50 вариантов × 5 моделей. Пары, которые уже есть в логе, пропускаются, поэтому
прерванный прогон можно продолжить. Другие параметры: `--k=50`, `--attempts=3`, `--models=a,b,c` (`id@medium` —
та же модель с явным усилием рассуждений), `--dev` (сид для настройки), `--log=файл`, `--jobs=4`, `--json=файл`.

```bash
node agent/selftest.js
```

Самопроверка без сети: фальшивые генераторы («отличник», «лжец», «исправляющийся», мусор, сбой API) и
мутационный фаззинг зануды.

```bash
node agent/agent.js --model=deepseek/deepseek-v4.1-flash --i=0
```

Один вариант вживую, с выводом всех попыток.

Ключ OpenRouter подставляет прокси окружения (хост `openrouter.ai`). Без прокси нужен `OPENROUTER_API_KEY`.

## Файлы

| Файл | Что делает |
|---|---|
| `variants.js` | Варианты № 47: тот же генератор, что в `core/test.js` (LCG + `T47.randomGamma`). `DEV_SEED = 2026` — для настройки промпта, `EVAL_SEED = 12345` — для замера. Условие в виде текста и обратное чтение текста (второй ввод для O9). |
| `prompt.js` | Промпт генератора: соглашения эпюра, справка по теории, действия `core/cp.js`, правила плана. `PROMPT_VERSION` пишется в каждый лог. |
| `llm.js` | OpenRouter `/chat/completions` без зависимостей: туннель CONNECT через `HTTPS_PROXY`. Повторы при сбоях сети, 429 и 5xx — это не попытки агента. |
| `plan.js` | Исполнитель: разбор JSON, проверка формата программы (действия, арность, типы, порядок, обязательные `K″`, `K′`, `|AK|`), исполнение `cp.exec`, вырождения (параллельные прямые, совпавшие точки). Правило «LLM не вычисляет»: числовой литерал допускается только как сторона ±1 у `perpOff`. |
| `exact-plan.js` | Второе исполнение того же плана — точно, в дробях, на ядре 2D `core/kernels.js`. Длины хранятся квадратами, точки циркуля — символически. Если план нельзя исполнить точно, это ошибка: такой план сертификат проверить не может, и ответ не выдаётся. |
| `nerd.js` | Зануда: план становится протоколом задачи того же вида, что `core/t47.js`. Ядро 3D находит K по определению, ядро 2D исполняет план. `core/certify.js` вызывается без изменений. Вердикт — только `ok` сертификата. Отсюда же текст ошибки для модели (без верного ответа) и качественные подсказки, которые на вердикт не влияют. |
| `agent.js` | Цикл: генератор → исполнитель → зануда → (ошибка → снова генератор, не больше N раз) → ответ или отказ. |
| `eval.js` | Оценка, воспроизведение по логам, контроль зануды. |
| `selftest.js` | Самопроверка без сети. |
| `logs/eval.jsonl` | Лог замера: вариант, модель, версия промпта, все попытки (текст ответа модели, план, этап, ошибки, обязательства сертификата, токены, стоимость), итог. |
| `logs/dev-2026.jsonl` | Лог настройки промпта на `DEV_SEED`. |

## Что проверяет зануда

`core/certify.js` вызывается как для `core/t47.js`. Протокол собирается в `nerd.js`:

- **O9** — условие, которое модель получила текстом и которое прочитано обратно из текста, совпадает с вариантом генератора;
- **O1** — проекции K″, K′ из плана и квадрат |AK| точно (в дробях) совпадают с ядром 3D, где K = a ∩ α, α ⟂ a через A;
- **O2, O3** — ответ удовлетворяет условию (K ∈ a, AK ⟂ a) и совпадает с независимым решателем `t47.spec.solve`;
- **O6** — ни одно пересечение плана не острее 8°;
- **O4, O5** — то, что выдаётся пользователю (координаты из `core/cp.js` и текст «|AK| ≈ N мм»), совпадает с доказанным;
- **O7** — тот же план как способ верен на 200 случайных вариантах данных.

Файлы `core/` и `tests/` не менялись.
