# Домашние задания

Здесь лежит всё, что относится к ДЗ: данные всех вариантов, методика и программа решения. Каждое ДЗ — своя папка.
На сайте — один раздел ДЗ на оба предмета, `#/dz`: все задания начерта и инженерной графики на одном экране,
«мой вариант» вписывается один раз на предмет. Путь студента — ДЗ → номер варианта → разбор; страница задания — это
выбор варианта (номера по типам, у ИГ — ещё и по картинке), остальное — кнопками внизу: «Условие», «Как решать»,
«Пример», «Ошибки и защита», «Сверить ответы». Прежние адреса (`#/ng/dz/…`, `#/ig/dz/…`, `#/dz/…`, `#/ig/hw2/…`)
переадресуются на короткие.

## Что в папке ДЗ

| Файл | Что в нём |
|---|---|
| `variants.js` | Данные всех 30 вариантов (`V[номер] = {точка: [x, y, z]}`, мм; x — влево от O, y — к зрителю, z — вверх) и **типы вариантов** (`types`: номера `from…to`, название, текст условия, какие точки даны, числа условия) |
| `method.js` | Методика: суть, главная мысль, для каждого типа — план по шагам с «почему так», что в ответе, самопроверка; типичные ошибки, вопросы защиты, что повторить |
| `solver.js` | Программа решения: строит по данным варианта разбор по шагам (чертёж каждого шага, 3D) и проверяет ответ условием задачи (сертификат) |
| `models.js` | (ИГ) 3D-модели деталей вариантов — по ним сайт строит виды, разрезы, шаги и лист |
| `README.md` | Коротко об этом ДЗ: типы, способ решения, файлы |

Все файлы дописывают одно описание задания в реестр: `DZR.def('ng2', {…})` (`kernel/dz.js`). Сайт и проверки
работают только через реестр:

```js
DZR.list('ng')           // задания курса по порядку
DZR.typeOf('ng2', 17)    // тип варианта 17 → {code:'2b', from:11, to:20, name, text, given, params}
DZR.solve('ng2', 17)     // {task — разбор в формате плеера, answers, cert — нарушения условия (пусто — верно)}
DZR.meta('ng2', 17)      // заголовок и данные для листа (kernel/sheet.js)
```

`ng/lib.js` — общие помощники решений начерта (`NGLIB`): видимость, прямые уровня плоскости, выбор плоскости-посредника,
замена плоскостей, ступени подсказок шага.

## Как добавить ДЗ или тип вариантов

1. Папка `dz/<курс>/<номер>/`, в ней `variants.js` с `types` и `V` (образец — `ng/2/variants.js`).
2. `method.js` — методика по типам (ключи `types` — коды типов).
3. `solver.js` — `DZR.def(id, {solve(n, D, src, d){…}, has(n){…}})`: программа построения от данных варианта.
   Всё, что меняется от варианта к варианту, выбирает правило в коде, а не ручная подгонка под числа.
4. Подключить файлы в `index.html` (блок «ДЗ: реестр…») и проверить: `node tests/variants-run.js --only=<id>`.

## Проверка

`node tests/variants-run.js` — каждый вариант строится и проходит те же проверки, что примеры сайта: условие и ответ
числами (ДЗ-оракул), 3D-проверка чертежа, «Евклид» (каждый элемент выводится линейкой и циркулем), арифметика в тексте,
сертификат решателя, лист А3 (без NaN, всё внутри рамки). Таблицы ДЗ №2 и №3 перенесены дважды независимо
(`core/dz-variants.js`) — совпадение проверяется там же.
