# ДЗ №2 · Многогранник по условиям

Без преобразования чертежа достроить многогранник, часть вершин которого задана условиями «лежит на прямой» и
«удалена на…».

| Варианты | Тип | Дано | Ключевая точка |
|---|---|---|---|
| 1–10 | 2а · пирамида SABC, высота 80 мм | A, B, C, E, F | S = EF ∩ β, β ∥ (ABC) на расстоянии 80 мм |
| 11–20 | 2б · прямая призма, AB = AC, высота 70 мм | B, C, E, F | A = EF ∩ μ, μ ⟂ BC через середину BC |
| 21–30 | 2в · куб, B на EF, AD на AK | A, K, E, F | B = EF ∩ μ, μ ⟂ AK через A |

**Как решается.** У недостающей вершины два условия — два множества точек (прямая и плоскость); вершина — их
пересечение. Точка встречи прямой с плоскостью — через проецирующую плоскость-посредник γ ⊃ EF (`gammaFor` выбирает
горизонтально- или фронтально-проецирующую). Перпендикуляр к плоскости — n′ ⟂ h′, n″ ⟂ f″; длины — на натуральной
величине. Видимость — по конкурирующим точкам.

| Файл | |
