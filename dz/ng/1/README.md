# ДЗ №1 · Плоская фигура на прямой

Дано: вершина **A** и прямая **MN** (во всех вариантах — прямая уровня). Построить фигуру со стороной **BC** на MN и
определить углы наклона высоты и плоскости фигуры к π₁ и π₂.

| Варианты | Фигура | Числа условия |
|---|---|---|
| 1–10 | равносторонний треугольник ABC | — |
| 11–20 | параллелограмм ABCD | BC = 100 мм, AB = 60 мм |
| 21–30 | равнобедренная трапеция ABCD | меньшее основание AD = высоте, диагонали 120 мм |

**Как решается.** MN — фронталь (y_M = y_N) или горизонталь (z_M = z_N); главное строим на той проекции, где она в
натуральную величину: перпендикуляр AK, затем способом совмещения — A₀ и размеры фигуры без искажений, обратно — по
линиям связи. Углы высоты — прямоугольными треугольниками, углы плоскости — линиями наибольшего ската.

| Файл | |
|---|---|

| `method.js` | методика по типам, ошибки, защита |
| `solver.js` | решатель: все 30 вариантов (сертификат — форма фигуры, BC ⊂ MN, углы по нормали) |
