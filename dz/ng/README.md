# Начертательная геометрия · ДЗ №1–5

| Папка | ДЗ | Как решается (одной строкой) |
|---|---|---|
| [`1/`](1/) | Плоская фигура на прямой | высота ⟂ MN там, где MN в натуральную величину; размеры фигуры — способом совмещения; углы — прямоугольными треугольниками и линией ската |
| [`2/`](2/) | Многогранник по условиям | недостающая вершина = пересечение двух «геометрических мест» (прямая ∩ плоскость), точка встречи — через плоскость-посредник |
| [`3/`](3/) | Пирамида: замена плоскостей и вращение | 1–2: одна и две замены плоскостей проекций; 3–4: вращение вокруг горизонтали |
| [`4/`](4/) | Линии пересечения поверхностей | для каждой пары тел свой посредник (плоскости уровня, концентрические или эксцентрические сферы), дающий окружности и прямые; опорные точки, видимость |
| [`5/`](5/) | Прямая и поверхность | плоскость через прямую, режущая поверхность по простым линиям; касательная плоскость и нормаль через h и f |

`lib.js` — общие помощники решений (`NGLIB`), их берут все `solver.js`.

На сайте: `#/ng/dz` — все ДЗ по начерту, `#/ng/dz/<номер>` — страница ДЗ, `#/ng/dz/<номер>/<вариант>` — разбор варианта.
