# ДЗ №3 · Пирамида: замена плоскостей и вращение

Дана пирамида SABC (варианты 1–30, один тип). Найти: 1) высоту; 2) угол между гранью SAB и основанием; 3) истинный
вид основания ABC; 4) угол ребра SA с основанием. 1–2 — заменой плоскостей проекций, 3–4 — вращением вокруг прямой
уровня.

**Как решается.** 1) ось x₁₄ ⟂ горизонтали основания — основание проецируется в прямую, высота — перпендикуляр к ней;
2) две замены — ребро AB в точку, грани в прямые, угол между ними; 3) вращение вокруг горизонтали основания до
положения ∥ π₁; 4) φ = 90° − ψ, ψ — угол SA с перпендикуляром к основанию, виден после вращения.
