# ДЗ №4 · Линии пересечения поверхностей

Три тела на одном чертеже-типе; размеры — из таблицы варианта. Построить проекции линий пересечения и обозначить
характерные точки. Решатель строит все 30 вариантов: разбор по шагам, 3D-модель тел, черновик и чистовик листа А3.

| Варианты | Чертёж-тип | Размеры в таблице | Посредники |
|---|---|---|---|
| 1–5 | полутор (R60, труба Ø80) с осью ⟂ π₂, конус вершиной вниз, полуцилиндр R40 ⟂ π₂ | Dк, Hк, Xк, Xц, Zц | тор ∩ полуцилиндр — фронтальные плоскости; тор ∩ конус — эксцентрические сферы |
| 6–10 | срезанная полусфера Ø160, усечённый конус, цилиндр Ø60 (оси вертикальные) | Dк, dк, Xк, Yк, Xц, Yц | горизонтальные плоскости |
| 11–15 | конус 60°, наклонный конус под φ, трёхгранная призма ⟂ π₂ | Dк, φ, α, β | конус ∩ конус — концентрические сферы; конус ∩ призма — горизонтальные плоскости |
| 16–20 | полусфера Ø150, трёхгранная призма, тор-«лимон» с осью ⟂ π₂ | Dп, Xп, Yп, Xт, Yт | сфера ∩ призма — горизонтальные плоскости; сфера ∩ тор — фронтальные плоскости |
| 21–25 | тор-«бочка» с горизонтальной осью, наклонный конус Ø120/Ø60, цилиндр ⟂ π₂ | Dт, Rт, Xт, Dц, Xц, Zц | горизонтальные плоскости |
| 26–30 | раструб (дуга R80) с цилиндром Ø40, наклонный цилиндр Ø50, цилиндр Ø60 ⟂ π₂ | Xц, Zц, α | раструб ∩ наклонный цилиндр — концентрические сферы; раструб ∩ цилиндр — горизонтальные плоскости |

**Как решается.** Для каждой пары тел — свой посредник, который режет обе поверхности по окружностям или прямым.
Сначала опорные точки (на очерках, высшая и низшая, на рёбрах, крайние посредники), потом промежуточные; соединение
по порядку; видимость; обводка очерков. Линия двух тел, лежащая внутри третьего, на чертеже не строится.

| Файл | |
|---|---|
| `variants.js` | таблица размеров 30 вариантов, шесть типов |
| `method.js` | методика по типам, ошибки, защита |
| `surf.js` | ядро поверхностей: тела (inside + куски поверхностей), линии пересечения по сетке параметров, очерки, видимость лучом |
| `solver.js` | тела каждого типа по размерам варианта, посредники, шаги разбора, 3D-сетка тел; `DZR.solve('ng4', n)` |

Проверка решения (`cert`): каждая точка линии лежит на обеих поверхностях, а линия, найденная на сетке одного тела,
совпадает с найденной на сетке другого (независимое построение) с точностью 0,35 мм.

Сайт: `#/ng/dz/4`, вариант — `#/ng/dz/4/<номер>`.
