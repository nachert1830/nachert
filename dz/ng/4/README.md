# ДЗ №4 · Линии пересечения поверхностей

Три тела на одном чертеже-типе; размеры — из таблицы варианта. Построить линии пересечения и обозначить характерные
точки.

| Варианты | Чертёж-тип | Размеры в таблице |
|---|---|---|
| 1–5 | полусфера, конус вершиной вниз, полуцилиндр R40 ⟂ π₂ | Dк, Hк, Xк, Xц, Zц |
| 6–10 | срезанная полусфера Ø160, усечённый конус, цилиндр Ø60 (оси вертикальные) | Dк, dк, Xк, Yк, Xц, Yц |
| 11–15 | срезанная полусфера Ø160, конус 60°, наклонный конус под φ | Dк, φ, α, β |
| 16–20 | полусфера Ø150, трёхгранная призма, тор | Dп, Xп, Yп, Xт, Yт |
| 21–25 | тор, наклонный усечённый конус, цилиндр ⟂ π₂ | Dт, Rт, Xт, Dц, Xц, Zц |
| 26–30 | раструб (дуга R80) и три цилиндра | Xц, Zц, α |

**Как решается.** Секущие плоскости (или концентрические сферы), дающие в сечении обеих поверхностей окружности и
прямые; сначала опорные точки (на очерках, высшие и низшие), потом промежуточные; соединение по порядку; видимость.
