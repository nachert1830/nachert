# ДЗ №5 · Прямая и поверхность, касательная плоскость

1) Точки пересечения прямой AB с поверхностью и видимость прямой; 2) касательная плоскость и нормаль в одной из точек.

| Варианты | Поверхность | Посредник |
|---|---|---|
| 1–10 | прямой круговой конус (основание Ø100 на z = 10, высота 120) | плоскость через AB и вершину — режет по образующим |
| 11–20 | наклонный цилиндр (основания Ø70 на z = 0 и 100) | плоскость через AB ∥ образующим — режет по образующим |
| 21–30 | поверхность вращения (дуга R120, вертикальная ось) | фронтально-проецирующая γ ⊃ AB, сечение по параллелям |

| Файл | |
|---|---|
| `variants.js` | 30 вариантов, размеры поверхностей — `params` типа |
| `method.js` | методика по типам, ошибки, защита |
| `solver-cone.js` | программа для конуса (она же — разобранный пример) |
| `solver.js` | цилиндр и поверхность вращения; решатель всех 30 вариантов с сертификатами (точки на AB и на поверхности, нормаль ⟂ касательным) |
