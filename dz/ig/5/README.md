# Инженерная графика · Задание №5 · Тело с отверстием и вырезом K

Тело (призма, пирамида, цилиндр или Λ-образная призма) со сквозным отверстием (цилиндр, конус или пирамида — шире сверху или снизу)
и вырезом K задано двумя-тремя изображениями. Построить три вида, необходимые разрезы (половина вида + половина разреза),
горизонтальный разрез А–А и нанести размеры.

| Файл | |
|---|---|
| `variants.js` | запись в реестре: условие, состав листа |
| `method.js` | методика: порядок построения, ошибки, защита |
| `models.js` | 3D-модели вариантов (дерево `IG3.P`): тело с отверстием (`body`), вырезы K (`cut`), уровень разреза А–А, размеры; что принято при чтении чертежа — `note` |
| `img/` | картинки вариантов (данные изображения задания): `node dz/ig/make-thumbs.js ig5 [номера]` |

Вырез K виден на одном из видов:
- на главном виде (`K` — многоугольник в плоскости xz, протянутый вдоль y);
- на виде слева (`kl:1`, отверстие вдоль x; в задании на виде слева дан только профиль K — `givenKL`, главный вид и вид сверху даны без выреза — `givenF`);
- на виде сверху (`vk:1`, вертикальное отверстие; вид сверху дан с ним).

Из модели сайт строит всё сам, тем же модулем, что ДЗ 2 и 4: данные виды, 3D, построение по шагам, лист А3 по ГОСТ — чистовик и черновик.

## Статус

Модели есть у 27 вариантов из 30. Варианты 17, 21 и 29 (составные тела: конус + цилиндр + призма с несколькими ступенями отверстия) ещё не
перенесены: часть размеров на чертеже не читается однозначно. У вариантов 2, 11, 13, 26 часть размеров снята с рисунка (`note` в модели).
У варианта 25 коническая вершина пересекает грани призмы — на чертеже кафедры линии пересечения не показаны, на листе сайта они даны кривыми.
Задание помечено на сайте как бета (`beta:true` в `variants.js`).
