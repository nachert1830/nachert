# Инженерная графика · ДЗ 1 · Сопряжения

Плоский контур детали на листе А4: центры от точки разметки (60*, 170*), сопряжения прямых и окружностей дугами,
касательные, отверстия, оси. По этому же заданию — РК1 по инже.

| Файл | Что в нём |
|---|---|
| `src/vNN.pdf` | условия вариантов (пока 1–4 из 30) |
| `variants.js` | вариант как программа построения: данные (`given`), сопряжения по порядку (`ops`), контуры обводки (`contours`), отверстия и оси (`draw`), что принято при чтении (`note`) |
| `draw.js` | `IG1D.steps(n)` — построение по шагам (SVG): оси → данные → для каждого сопряжения ГМТ центров, центр, точки касания → обводка; `IG1D.sheet(n)` — лист А4 |
| `../../../core/conj.js` | ядро: построитель (как студент циркулем) и независимый проверяющий (определение касания, гладкость контура) |

Проверка — `node tests/ig1.js`. Статус: варианты 1–4 перенесены и проходят проверку; 5–30 — ждём условия.
