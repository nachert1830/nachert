# ИГ: служебная база «каждая линия»

`node dz/ig/etalon/make.js ig6` (все варианты задания) или `node dz/ig/etalon/make.js ig5 7` (один вариант) — из
3D-модели варианта (`dz/ig/<N>/models.js`) пишет `dz/ig/<N>/lines/vNN.json`. Сайт эти файлы не грузит и нигде не
показывает: шаги на сайте остаются короткими, а происхождение каждой линии лежит здесь. После правки модели варианта —
перезапустить для него.

## Формат `lines/vNN.json`

```js
{ v:1, dz:'ig6', n:5, title, box,                   // формат, задание, вариант, название детали, габарит (мм)
  views:{F:'главный вид', T:'вид сверху', L:'вид слева'},
  feats:[{i, name, kind}],                            // элементы детали — те же, что в шагах сайта (IG3.features): тело / отверстие
  lines:[{ id:'l125', v:'L',                          // линия на виде
    vis:1, t:'s',                                     // 1 — видимая, 0 — штриховая; 's' — отрезок, 'a' — кривая
    p:[[x,y,z]…],                                     // мм модели: концы (у кривой — ещё середина)
    fe:2,                                             // чья линия (feats)
    s:['грань x = −25','грань z = −15'],              // пересечение каких поверхностей (одна — очерк)
    step:'Вырез',                                     // название шага сайта, где линия появляется ('Дано' — дана в задании)
    how:{ given:1 }                                   // дана в задании, или:
       | { x:'F'|'T', z:'F'|[мм…], y:[мм…],           // откуда положение по x, высота, координата y концов
           rad:{ r, R, d, trace, src } } }]}          // дуга среза шара: r = √(R² − d²), радиус со следа trace на виде src
```

Поверхности: грани брусков (`грань x = …`), сферы (`сфера R…`), цилиндры (`цилиндр Ø…`), торцы, плоскости срезов;
у призм, пирамид и конусов — `поверхность: призма / пирамида / конус`.

## Статус

ДЗ 5 и ДЗ 6 — все варианты с моделью; линии главного вида, вида сверху и вида слева. Линии разрезов — следующим шагом.
