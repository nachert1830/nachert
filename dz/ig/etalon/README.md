# Эталон шагов ИГ: два уровня подробности

`node dz/ig/etalon/make.js ig6 5` — из 3D-модели варианта (`dz/ig/<N>/models.js`) делает:

1. **Шаги для всех** — `lk/etalon-ig6-5/index.html` (пока страница в кабинете). Только картинки, без текста. На шаге — один
   элемент на одном виде: он подсвечен там, где дан, к новым линиям идут линии связи, новые линии — цветом. На следующем
   шаге подсветка гаснет, линии становятся обычными. Порядок: дано → шар → полость → каждое отверстие на каждый
   недостающий вид → профильный разрез → разрез А–А → итог.
   - высота — горизонтальной линией связи с главного вида; положение по x — вертикальной;
   - координата y — отрезком (синим): на виде сверху от оси x до точки, на виде слева тот же отрезок от оси z
     (оси эпюра x, y, z, O; построений справа снизу нет); передняя половина — задняя симметрична;
   - дуга среза шара — радиусом (фиолетовым) со следа грани: где грань видна прямой, отрезок от оси до контура сферы.
2. **Полные данные «каждая линия»** — `dz/ig/<N>/lines/vNN.json`. Сайт их не грузит; их читает ассистент, когда человек
   спрашивает «как построить эту линию».

## Формат `lines/vNN.json`

```js
{ v:1, dz:'ig6', n:5, R:55, r:37.5,                 // формат, задание, вариант, радиусы шара и полости
  views:{F:'главный вид', T:'вид сверху', L:'вид слева'},
  feats:[{i, name}],                                  // элементы детали: шар, полость, отверстия K (как и где заданы)
  steps:[{i, k, fe, v, src}],                         // публичные шаги: k — given|feat|secL|aa|done; fe — элемент, v — вид, src — откуда
  lines:[{ id:'l122', v:'L',                          // линия на виде
    vis:1, t:'a',                                     // 1 — видимая, 0 — штриховая; 'a' — дуга, 's' — отрезок
    p:[[x,y,z]…],                                     // мм модели: концы (у дуги — ещё середина)
    fe:2,                                             // чья линия (feats)
    s:['сфера R55','грань x = −25'],                  // пересечение каких поверхностей (одна — очерк)
    st:4,                                             // на каком публичном шаге появляется (0 — дано)
    how:{ given:1 }                                   // дана в задании, или:
       | { z:'F', x:'F'|'T', y:[мм…], z:[мм…],        // откуда высота / положение по x / координата y
           rad:{ r, R, d, trace, src } } }]}          // дуга: окружность r = √(R² − d²), радиус со следа trace на виде src
```

## Статус

Сделан эталон на ДЗ 6, вариант 5. Разрезы (профильный, А–А) в шагах — готовой картинкой с подсвеченной секущей
плоскостью; в данных пока линии видов (главный, сверху, слева), линии разрезов — следующим шагом.
