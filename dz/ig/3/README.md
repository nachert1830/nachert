# Инженерная графика · Задание №3 · Корпусная деталь

Корпусная деталь (основание, приливы, карманы, рёбра, отверстия) задана главным видом и видом сверху. Построить вид
слева, разрезы — в том числе ступенчатый А–А через оси отверстий — и нанести размеры по ГОСТ 2.307.

| Файл | |
|---|---|
| `variants.js` | запись в реестре: условие, состав листа |
| `method.js` | методика: порядок построения, ошибки, защита |
| `models.js` | 3D-модели 30 вариантов (дерево `IG3.P`): тело, участки ступенчатого разреза (`step`), размеры листа; что принято при чтении чертежа — `note` |

Из модели сайт строит всё сам, тем же модулем, что задания 2 и 4: данные виды, вид слева, 3D, построение по шагам,
лист А3/А2 — чистовик и черновик. Правила выбирает программа:

- ступенчатый разрез — секущие плоскости y = const на участках по x (`step`); переходы между ними на разрезе не
  изображают, на виде сверху — след с изломами и буквами (ГОСТ 2.305);
- половина вида и половина разреза — только при симметричном изображении, иначе полный разрез;
- плавный переход (плоскость, касательная к цилиндру) линией не изображают.

Сайт: `#/dz/ig3`, вариант — `#/dz/ig3/7`.
