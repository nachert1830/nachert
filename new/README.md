# /new/ — копия сайта с новым дизайном

Полная копия сайта по адресу **nachert1830.ru/new/** (вход по коду 1830 — занавеска, не защита). Поисковикам закрыта
(`noindex`), ссылок на неё с сайта нет. Пользователи видят старый сайт. Когда копия готова — ею заменяют оригинал.

| Файл | Что это |
|---|---|
| `index.html` | Копия корневого `index.html`: те же разделы, данные и проверки; пути к общим файлам — `../` (ядро, ДЗ, шрифты, картинки, кабинет). Правки вида делать здесь. |
| `shell.css`, `shell.js` | Новый дизайн поверх копии: главная, экраны предметов (тумблер «Начерт / Инжа»), ползунок «добавь иконку», окно входа. Показывается на `#/`; любой другой адрес — разделы сайта. Собирает `make-shell.py` из `docs/redesign/home-v13/mockup.html`. |
| `dzdeck.css`, `dzdeck.js` | Экран «ДЗ» (адрес `#/dz`): колода карточек по сроку сдачи, как в Wallet — прошедшие полосками сверху, следующие снизу, по умолчанию раскрыто ближайшее несданное. Листание — свой движок (палец ведёт колоду 1:1, отпустил — инерция и пружина к ближайшей карточке, резинка у краёв; колесо и стрелки тоже), отклик: на Android — вибрация на каждую карточку; на iPhone у сайтов вибрации нет, а системный щелчок с iOS 26.5 даёт только настоящее касание переключателя, поэтому всё нажимаемое накрыто прозрачной подписью скрытого `<input switch>` (`.hl`) — щелчок на каждое касание, а при ведении пальцем колода «прилипает» к каждой карточке, толчок сильнее в конце колоды и при раскрытии. Нажатие раскрывает карточку: вкладки задания и «Открыть мой вариант». Задания — из `DZR`, вариант — общий для сайта (`dzvar`). Перенесено из макета `docs/redesign/dz-picker/` (ветка `claude/sharp-newton-49vuqd`). **Сроки сдачи черновые** (таблица `LOOK` в `dzdeck.js`, недели семестра) — вписать по плану кафедры. |
| `fork.py` | Делает копию заново из корневого `index.html` (**затирает правки копии** — только если копия ещё не правилась). |
| `make-shell.py` | Пересобирает `shell.css`/`shell.js` из макета. |

- Главная и экраны предметов начинаются с карточки «Учиться» (`learn()` в `shell.js`): ведёт в путь подготовки к заданию,
  которое сайт выбрал по сроку (`PREP.autoKey`), с текущим навыком и прогрессом.
- Только в копии: подготовка по навыкам к каждому ДЗ и РК (разбор → тест) (`../prep/plans.js`, `#/prep`), экран «Сначала — подготовка»
  перед вариантом (`PREP.gate` в `dzVariant`), карточки подготовки на страницах ДЗ и РК, пункт «Подготовка к ДЗ и РК» на главных
  предметов (docs/prep/README.md). Основной сайт этого не показывает.
- Общие с оригиналом: данные и решатели ДЗ (`dz/`, `kernel/`), кабинет (`lk/`), прогресс и вариант (тот же `localStorage`).
  Вход в кабинет из копии возвращает в копию (`lk_ret = /new/`, `lk/app.js` — `goRet`).
- Изменения содержимого на основном сайте (новые задачи, ДЗ в `index.html`) в копию сами не попадают — переносить вручную
  или, пока копия не правилась, пересобрать `fork.py`.
- Замена оригинала: вернуть пути (`../` → без приставки), перенести `shell.*` в корень, убрать `noindex` и занавеску.
