# /new/ — копия сайта с новым дизайном

Полная копия сайта по адресу **nachert1830.ru/new/** (вход по коду 1830 — занавеска, не защита). Поисковикам закрыта
(`noindex`), ссылок на неё с сайта нет. Пользователи видят старый сайт. Когда копия готова — ею заменяют оригинал.

| Файл | Что это |
|---|---|
| `index.html` | Копия корневого `index.html`: те же разделы, данные и проверки; пути к общим файлам — `../` (ядро, ДЗ, шрифты, картинки, кабинет). Правки вида делать здесь. |
| `shell.css`, `shell.js` | Новый дизайн поверх копии: главная, экраны предметов (тумблер «Начерт / Инжа»), ползунок «добавь иконку», окно входа. Показывается на `#/`; любой другой адрес — разделы сайта. Собирает `make-shell.py` из `docs/redesign/home-v13/mockup.html`. |
| `dzdeck.css`, `dzdeck.js` | **Своя копия колоды** (подключена в `index.html` вместо `../dz/deck.*`; основной сайт не меняется): два предмета — Начерт / Инж. графика, без «Все»; смена предмета закрывает раскрытую карточку. Экран «ДЗ» (адрес `#/dz`): колода карточек по сроку сдачи, как в Wallet — прошедшие полосками сверху, следующие снизу, по умолчанию раскрыто ближайшее несданное. Листание — свой движок (палец ведёт колоду 1:1, отпустил — инерция и пружина к ближайшей карточке, резинка у краёв; колесо и стрелки тоже), отклик: на Android — вибрация на каждую карточку; на iPhone у сайтов вибрации нет, а системный щелчок с iOS 26.5 даёт только настоящее касание переключателя, поэтому всё нажимаемое накрыто прозрачной подписью скрытого `<input switch>` (`.hl`) — щелчок на каждое касание, а при ведении пальцем колода «прилипает» к каждой карточке, толчок сильнее в конце колоды и при раскрытии. Нажатие раскрывает карточку: вкладки задания и «Открыть мой вариант». Задания — из `DZR`, вариант — общий для сайта (`dzvar`). Перенесено из макета `docs/redesign/dz-picker/` (ветка `claude/sharp-newton-49vuqd`). **Сроки сдачи черновые** (таблица `LOOK` в `dzdeck.js`, недели семестра) — вписать по плану кафедры. |
| `method.js`, `method.css` | **Методичка задания** (`#/ng4`, `#/ng4/how`, `#/ng4/faq`, `#/ng4/m/<глава>`) — страница каждого ДЗ; список ДЗ предмета (`METHOD.dzList`), «Сдаётся скоро» на главной (`METHOD.homeNow`), плашка «Методичка» в разборе варианта (`METHOD.strip`), кнопки колоды «ДЗ» (`window.dzDeckGo`). Подробно — ниже, «Путь студента». |
| `luka.js`, `luka.css` | **Лука — ИИ-агент на чертеже** (версия 2.1, эскиз). Пингвин в левом нижнем углу чертежа: начерт ДЗ №4–5 и задачи тетради с 68-й (ИГ — следующим шагом). Ответы в 4 ступени: кнопки по шагу (из решателя: шаг, «почему так», намёк, числа, «проверь себя»; термины — словарь `GLOSS`; частая ошибка — методика ДЗ) → свой вопрос через разборщик с уверенностью 0…1 → при средней уверенности «Ты про это?» → при низкой ИИ (`/api/tutor/chat`, режим explain). Вопросы без заготовки — `localStorage luka_inbox` и событие `TRACK luka`; 👍/👎 — `luka_rate`. Плеер подключает Луку опцией `luka:{dz,n}` или `{task}`. |
| `map/` | **Прототип дизайна 2.0** — карта семестра (`/new/map/`): иллюстрированные острова ДЗ и лавовые РК, все уровни открыты (бледные — не пройдены), плашка уровня («Суть за минуту», «Приступить», «Теория»), пример по шагам с персонажем в углу чертежа, проверка из 3 вопросов с «Уверен / Сомневаюсь», экран «пройден». Карта снизу вверх; маскот — пингвин (эскиз, финального рисует аниматор). Кнопка «Прототип» — сводка «Как поняли материал». Исходник — `map/proto.html` (его же публикуем артефактом), `map/build.py` собирает `map/index.html`. Прогресс и ответы — `localStorage np2_*`. |
| `fork.py` | Делает копию заново из корневого `index.html` (**затирает правки копии** — только если копия ещё не правилась). |
| `make-shell.py` | Пересобирает `shell.css`/`shell.js` из макета. |

- **Методический сервис, а не ГДЗ:** язык «разбора и метода» вместо «решения» («Разберись со своей задачей», «Разбор по шагам»,
  «Сразу к разбору»), свой вариант начерта — сначала «Решаю сам», страница «Как мы учим» (`#/method`, `viewMethod`): путь к заданию,
  принципы с исследованиями, откуда содержание; ссылки — подвал, «О проекте», экран выбора перед вариантом.
- **Карточка задания** (`dzCard`; с методичкой — только запасной вид, если `method.js` не загрузился): курс и номер, название, срок («Сдать до …», через сколько дней), суть задания
  и **«Путь к сдаче»** (`dzPath` — данные, `dzRoute` — разметка): 1 Подготовка (уровни карты), 2 Метод («Как решать»),
  3 Свой вариант (номер раскрывается сеткой; «Другой вариант»), 4 Самопроверка («Ошибки и защита», «Сверить ответы», нормоконтроль).
  Пройденное — ✓ (посещения — `localStorage nch_dzseen`), «Сейчас» — первый непройденный шаг; строка шага нажимается целиком.
  Адрес задания больше не перебрасывает сразу в разбор варианта; «Назад» из разделов и разбора — к карточке задания.
  Раскрытая карточка колоды «ДЗ» показывает те же 4 шага (`window.dzPath`) в стиле колоды.
- Главная и экраны предметов начинаются с карточки «Учиться» (`learn()` в `shell.js`): открывает карту подготовки у задания,
  которое сайт выбрал по сроку (`PREP.autoKey`), с текущим навыком и прогрессом.
- Только в копии: карта подготовки (`../prep/world.js`, навыки — `../prep/plans.js`; `#/prep`) — задания семестра зонами,
  в каждой уровни-навыки (карточка уровня → условие → разбор → итог → тест → звёзды) и само задание в конце; экран выбора «Пройти подготовку / Посмотреть решение»
  перед вариантом (`PREP.gate` в `dzVariant`); карточки подготовки на страницах ДЗ и РК; пункт «Подготовка к ДЗ и РК» на главных
  предметов (docs/prep/README.md). Основной сайт этого не показывает.
- Общие с оригиналом: данные и решатели ДЗ (`dz/`, `kernel/`), кабинет (`lk/`), прогресс и вариант (тот же `localStorage`).
  Вход в кабинет из копии возвращает в копию (`lk_ret = /new/`, `lk/app.js` — `goRet`).
- Изменения содержимого на основном сайте (новые задачи, ДЗ в `index.html`) в копию сами не попадают — переносить вручную
  или, пока копия не правилась, пересобрать `fork.py`.
- Замена оригинала: вернуть пути (`../` → без приставки), перенести `shell.*` в корень, убрать `noindex` и занавеску.

## Путь студента: «надо сдать ДЗ №4» → методичка, решение — в одно касание

Студент приходит с задачей «сделать ДЗ», а не «прочитать методику». Поэтому любой вход в задание ведёт в **методичку**,
а решение своего варианта всегда видно и открывается одним нажатием — без поиска и без выбора между десятью вкладками.

| Где студент | Что видит | Куда ведёт |
|---|---|---|
| Главная | «Сдаётся скоро» — ближайшее ДЗ каждого предмета: срок, прогресс методички, **Методичка / Продолжить** и **Решение · вар. N** (или «Выбрать вариант») | `#/ng4`, `#/ng4/13` |
| Поиск «дз 4» / «дз 4 13» | методичка задания; на «дз 4 13» — разбор варианта и вторым — методичка | `#/ng4`, `#/ng4/13` |
| Колода «ДЗ» (`#/dz`) | раскрытая карточка: «Путь к сдаче» (шаг 2 — «Методичка»), **Открыть методичку** и **Сразу решение · вариант N** | `#/ng4`, `#/ng4/13` |
| Главная предмета (`#/ng`, `#/ig`) | «Выбери задание» — все ДЗ по сроку, «Сейчас» у ближайшего, прогресс методички, «решение вар. N» справа; номер варианта — кнопкой в углу | `#/ngN`, `#/ngN/вар` |
| **Методичка** (`#/ng4`) | шапка (срок, число глав, ≈ минут) → «Твой вариант N» (Сменить / Выбрать — сетка номеров прямо тут) → две двери: **Разобраться по методичке** (или «Продолжить: дальше «…»») и **Сразу решение** → содержание → главы | |
| Главы методички | **Понять:** 1 Задание (суть, твой тип, что на листе) · 2 Что нужно уметь (навыки подготовки с ✓, «Пройти подготовку», что повторить) · 3 Главная мысль. **Решить:** 4 Алгоритм (только своего типа; шаги — чек-лист с галочками, «Почему так?» закрыто — сначала объясни сам; остальные типы свёрнуты) · 5 Пример по шагам · 6 Твой вариант («Решаю сам» / «Смотреть решение», черновик, чистовик) · 7 Оформление листа. **Сдать:** 8 Проверь себя (чек-лист, «Сверить ответы», нормоконтроль) · 9 Типичные ошибки · 10 Защита (карточки: ответь вслух → открой → «знал / не знал», незнакомые — ещё раз) | |
| Навигация в методичке | телефон — нижняя панель: «Глава i из N · название» (открывает содержание) и **Решение · вар. N**; компьютер — слева содержание с прогрессом и кнопкой решения | |
| Разбор варианта начерта (`#/ng4/13`) | только шапка («← Назад» в методичку, «вариант N», значок «Поделиться») и чертёж по шагам — решение автора, без вкладок, плашки методички, «Смотрю / Решаю сам» и «▶ Поверхность»; «Не сходится с условием?» — внизу пояснения шага. Чистовик — кнопкой в конце разбора. На телефоне пояснение — шторка: тянешь ручку вверх/вниз, высота запоминается (`nch_plsh`); касание ручки — свёрнуто ↔ полэкрана. Наставник (`../lk/tutor.js`) в копии пока выключен | |
| Экран «подготовка или решение» (открыл вариант по ссылке) | «Пройти подготовку» · **Открыть методичку задания** · «Сразу к разбору» | |

- Кнопки «Решение» с главной, списка, колоды и методички не показывают экран «подготовка или решение» второй раз
  (`PREP.skipGate`) и открывают разбор начерта в режиме «Смотрю»; «Решаю сам» в главе «Твой вариант» — в режиме «Решаю сам».
- Прочитанной глава считается, когда её конец прокручен на экран; прогресс — в содержании, в двери «Продолжить», на главной
  и в списке ДЗ. Галочки шагов, «Проверь себя», ответы защиты и прочитанное — `localStorage nch_mk` (только в браузере).
- Методика: worked example → fading (пример, потом «Решаю сам» с подсказками), self-explanation («Почему так?» закрыто),
  retrieval practice (карточки защиты), чек-листы для самопроверки — docs/learning-methods.md.
- Проверки: `node tests/new-copy.js` (главы, только свой тип, «Сразу решение» → свой вариант, галочки и защита помнятся,
  `#/ng4/how` открывает «Алгоритм», выбор варианта в методичке, плашка и вкладка в разборе, кнопки колоды, «Сдаётся скоро»),
  `node tests/prep.js` (глава «Что нужно уметь», экран выбора с «Открыть методичку»).
