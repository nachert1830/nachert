# /m/ — копия сайта с методичкой

Полная копия сайта по адресу **nachert1830.ru/m/**, поисковикам закрыта (`noindex`), ссылок на неё с сайта нет. Здесь сайт
перестраивается из решалки в методичку; когда слой проверен — его переносят в основной сайт (и в копию дизайна `/new/`).

| Файл | Что это |
|---|---|
| `index.html` | Копия корневого `index.html` + точки подключения методички. **Руками не править** — собирается `fork.py`. |
| `fork.py` | Собирает копию из свежего корня: пути к общим файлам `../` (как `new/fork.py`) и 11 точек подключения. Каждая ищет ровно одно место в коде и падает, если его нет: методичка не теряется при обновлении основного сайта. `python3 m/fork.py` — собрать, `--check` — только проверить. |
| `metod.js` | Модуль `METOD`: модель знаний, экран «Методичка», приёмы в плеере. |
| `metod.css` | Стили методички (токены сайта). |

Данные и решатели ДЗ, программа тем (`kernel/prep.js`), тренажёр «найди ошибку» (`prep/`) — общие с основным сайтом.

## Что меняется для студента

**Главная — методичка** (`#/`, `#/m`). 53 темы курса по порядку (программа `PREPROG`). В каждой теме четыре шага:

| Шаг | Где | Засчитан, когда |
|---|---|---|
| 1. Разбери пример | первая задача тетради темы, режим «Смотрю» | задача пройдена до ответа |
| 2. Найди ошибку | тема подготовки `#/prep/<id>` (дуэль двух чертежей) | тема «освоена» моделью подготовки |
| 3. Реши сам | другая задача той же темы, «Решаю сам» | оценка по фактам ≥ «с ошибками» |
| 4. Повтори | та же тема через 1 → 3 → 7 → 16 → 35 дней, задача на новых числах (`GEN`) | по расписанию |

Блок «Сегодня» — следующая тема и что пора повторить. «Перед домашним заданием» — только темы, на которых стоит ДЗ №1–5,
со всем, на что они опираются (`#/m/dz/ng4`). Прежняя главная — `#/home`.

**Разбор задачи** (все задачи тетради, ДЗ по начерту, билеты — везде, где работает плеер):

- **«Смотрю»:** перед каждым шагом — «Как думаешь, что дальше?» из трёх вариантов (верный шаг и два других шага той же задачи,
  ближайшие следующие: правдоподобны, но рано). «Просто показать» и «Не спрашивать» оставлены — студент не заперт.
  Блок «Почему» открывается после «Объяснил — сверить».
- **«Решаю сам»:** шаг проверяется по частям. Сначала выбрать действие из трёх (или «Не знаю»). Затем, если на шаге появляется
  новая подписанная точка, — построить на бумаге и коснуться чертежа, где она окажется. Ответ сверяется с вычисленным
  положением точки; допуск — 3 % чертежа, но не меньше подушечки пальца; в задачах тетради ошибка показывается в мм.
  После этого «Сверить с построением»: на чертеже видны отметка студента (красная) и верное место (зелёное кольцо).
  Построение показывается только после попытки.
- **Оценка в конце — по фактам:** доля верных действий и точек. ≥ 80 % — «решил сам», ≥ 45 % — «с ошибками», иначе
  «пока не вышло». Оценка задаёт интервал повтора задачи (`LEARN`) вместо прежнего «Как получилось?».
- **Режим по уровню:** задача, которую студент уже открывал, и задача темы, где пример уже разобран, открываются в
  «Решаю сам»; первая встреча с темой — в «Смотрю». Явный адрес `…/try` и выбор режима студентом сильнее.
- В конце разбора — «Теперь реши сам», «Та же задача на новых числах», ссылки на темы задачи.

## Почему так (исследования)

| Приём | Источник | Где |
|---|---|---|
| Разобранный пример → задача | Sweller, Cooper, 1985; Renkl, Atkinson, 2003 | шаги 1 и 3 темы |
| Подсказки убираются по уровню | Kalyuga и др., 2003 (эффект обратной экспертности) | режим по уровню |
| Предсказание, эффект генерации | Slamecka, Graf, 1978; Bjork, 1994 | «Что дальше?» в «Смотрю» |
| Самообъяснение | Chi и др., 1989; Renkl, 1997 | «Почему» после объяснения себе |
| Проверка шагов, а не ответа | VanLehn, 2011 (d ≈ 0,76 против 0,31) | действие + точка на каждом шаге |
| Подсказка после попытки | Aleven и др., 2003; Baker и др., 2004 | построение — после выбора и касания |
| Самооценка ненадёжна | Dunlosky, Rawson, 2012 | оценка по фактам |
| Интервальное повторение, перемешивание | Cepeda и др., 2006; Rohrer, Taylor, 2007 | шаг 4, задачи на новых числах |

## Модель знаний

`localStorage` `nch_m` — только в браузере: по задаче — сколько раз и в каком режиме пройдена, лучшая оценка, доля
угаданных шагов; журнал последних 400 разборов. Тема собирается из задач тетради (`PREPROG.ALL[].wb`), статуса подготовки
(`PREP.status`) и очереди повторения (`LEARN`). Прогресс основного сайта учитывается: задача, дочитанная до ответа
(`ST 'wb3'`), засчитывается как разобранный пример. События — `TRACK('m_done', {mode, task, rate})`.

## Проверено (20.11.2026)

Обход в Chromium: все 89 задач тетради в «Смотрю» и «Решаю сам» (178 разборов до конца, 0 ошибок страницы; вопрос «что дальше»
на 745 шагах, точка касанием на 459), ДЗ №1–5 в обоих режимах, задачи на новых числах, экраны методички, темы, курса ДЗ,
телефон 390 px. Попадание в точку и промах проверены касанием (промах — «мимо на 34 мм», попадание — «ошибка 1,9 мм»).
Автоматической проверки копии в `tests/` пока нет — следующий шаг.

## Чего ещё нет

- Инженерная графика: варианты ИГ показываются своим просмотрщиком, не плеером, — режима «сначала сам» там пока нет;
  программы тем по ИГ нет.
- Шаги без новой подписанной точки проверяются только выбором действия (≈ 40 % шагов в «Решаю сам»).
- Неверные варианты действия — шаги той же задачи; ручных «ловушек» к шагам (типичная ошибка как вариант) пока нет.
- Синхронизация модели с кабинетом и замер «прирост на пробном РК» — после переноса на основной сайт.
