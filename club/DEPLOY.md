# Клуб: как запустить и обновлять — всё в браузере

Терминал, архивы и VPN больше не нужны. Всё устроено так:

- **Страница клуба** — `https://nachert1830.ru/club/`. Она лежит в этом репозитории (папка `club/`) и публикуется
  вместе с сайтом (GitHub Pages). С основного сайта на неё нет ссылок, поисковикам она закрыта (`noindex`). Без входа
  видна только кнопка «Войти», а войти может только тот, кого пригласили.
- **Сервер клуба** работает в Yandex Cloud (данные в России): аккаунты, прогресс, приглашения, бот. Он уже создан.
- **Обновляет облако сам GitHub.** При каждом изменении папок `club/` или `server/` запускается
  «Клуб — развёртывание в Yandex Cloud» (вкладка **Actions** репозитория): проверки → новая версия в облаке → бот.
- **Вход** — через **Яндекс ID** или **Telegram-бота**. К одному аккаунту можно привязать оба способа
  («Настройки» → «Способы входа»).

Сделать руками нужно один раз — три шага по 5 минут. Если что-то непонятно или красное — пришлите Claude скриншот
(только не присылайте содержимое ключей и секретов).

---

## Шаг 1. Ключ, которым GitHub обновляет облако

1. Откройте https://console.yandex.cloud → каталог **default** (тот, где уже лежит клуб).
2. В поиске сверху наберите **«Сервисные аккаунты»** → откройте → **«Создать сервисный аккаунт»**.
   - Имя: `github-deploy`.
   - **Роли в каталоге** → «Добавить роль» → `admin`. (Это «робот», который будет создавать и обновлять части клуба.
     Ему нужен полный доступ, но только к этому каталогу.)
   - «Создать».
3. Откройте `github-deploy` → сверху **«Создать новый ключ»** → **«Создать авторизованный ключ»** → «Создать» →
   **«Скачать файл с ключами»**. Скачается `authorized_key.json`.
4. Откройте этот файл Блокнотом → Ctrl+A → Ctrl+C. Он понадобится в шаге 3.

## Шаг 2. Приложение «Войти с Яндекс ID»

1. Откройте https://oauth.yandex.ru → **«Создать приложение»** (войдите своим Яндексом).
2. Название: `Клуб Начерта`. Платформа: **«Веб-сервисы»**.
3. **Redirect URI** — вставьте ровно это:
   ```
   https://d5d8eabs4lpi7jqnu2ha.4kscn31j.apigw.yandexcloud.net/api/auth/yandex/callback
   ```
   «Suggest Hostname» (если спросит): `nachert1830.ru`.
4. **Доступы**: только **«Доступ к логину, имени и фамилии, полу»** (раздел «Яндекс ID»). Больше ничего не отмечайте —
   почта, телефон и прочее клубу не нужны.
5. «Создать приложение». На странице приложения будут **ClientID** и **Client secret** — понадобятся в шаге 3.

## Шаг 3. Секреты в GitHub

https://github.com/nachert1830/nachert → **Settings** → слева **Secrets and variables** → **Actions** →
**New repository secret**. Добавьте четыре секрета (Name — слева, Secret — справа):

| Name | Что вставить |
|---|---|
| `YC_SA_KEY` | всё содержимое `authorized_key.json` из шага 1 |
| `YANDEX_CLIENT_ID` | ClientID из шага 2 |
| `YANDEX_CLIENT_SECRET` | Client secret из шага 2 |
| `OWNER_YANDEX_LOGIN` | ваш логин в Яндексе — то, что до `@yandex.ru`. С ним вы станете админом |

Токен бота и ваш Telegram id уже лежат в облаке с прошлого развёртывания — их добавлять не нужно.
После этого удалите `authorized_key.json` с компьютера: копия есть только в секретах GitHub, увидеть её там нельзя.

Готово. Напишите Claude «секреты добавил» — он сам запустит развёртывание и проверит, что всё зелёное.
(Или сами: **Actions** → последний запуск «Клуб — развёртывание…» → **Re-run all jobs**.)

## Как войти

- Сейчас: откройте `https://d5d8eabs4lpi7jqnu2ha.4kscn31j.apigw.yandexcloud.net/` → **«Войти с Яндекс ID»** →
  «Разрешить» → отметьте документы → «Войти». Вы — владелец (админ).
- После того как ветка клуба слита в `main` (pull request → Merge): клуб открывается по `https://nachert1830.ru/club/`.
  Ссылки входа и приглашений переключатся на этот адрес сами при следующем развёртывании.
- **Вход через Telegram** на nachert1830.ru/club/ — официальный: страница Telegram → подтверждение в приложении Telegram
  (сообщение приходит от самого Telegram). Нужно один раз сказать Telegram адрес сайта: в Telegram откройте **@BotFather** →
  `/setdomain` → выберите бота клуба → отправьте `nachert1830.ru`. Если у человека страница Telegram не открывается, под
  кнопкой есть «Войти через бота клуба»: «Старт» у бота → кнопка «Войти в клуб».
- На адресе облака (`….apigw.yandexcloud.net`) Telegram-вход — только через бота клуба: официальный вход Telegram
  привязан к одному сайту.

## Пригласить тестировщика

«Ещё» → «Админ-панель» → **«Приглашения»** → «Для кого» (например, «Аня, ИУ5») → «Создать приглашение» →
скопируйте ссылку и отправьте лично. Ссылка показывается один раз и срабатывает один раз. Тестировщик открывает её и
входит через Яндекс ID или Telegram.

Там же: вкладка **«Семестр»** — дата понедельника первой учебной недели (по умолчанию 31.08.2026), **«Функции»** —
включить и выключить функции, **«Отзывы»** — отзывы и обращения.

## Если что-то сломалось

- **Красный крестик в Actions.** Откройте запуск → шаг с крестиком: внизу будет понятная строка с «✖» или
  «::error::» — что именно не задано или не получилось. Пришлите её Claude.
- **«Яндекс ID сейчас не ответил»** при входе — проверьте, что Redirect URI в приложении на oauth.yandex.ru совпадает
  с адресом из шага 2 буква в букву.
- **Токен бота утёк.** @BotFather → `/revoke` → новый токен → добавьте его секретом `TG_BOT_TOKEN` в GitHub и
  перезапустите развёртывание: скрипт заменит токен в облаке. После этого секрет можно удалить.
- **Удалить клуб полностью.** Консоль Yandex Cloud → каталог → удалите базу `club`, функции `nachert-club-*`, шлюз
  `nachert-club`, секрет `club-secrets`. Удалятся все данные участников — по правилам клуба их нужно предупредить
  за 14 дней.

## Документы и закон (коротко)

Соглашение, политика и согласие лежат в `club/legal/` — это итоговые версии. Реквизиты: «Андрей Матханов, физическое
лицо», связь — через форму «Обращение к владельцу» в клубе. Если поменяете тексты, увеличьте `DOCS_VERSION` в
`server/lib/app.js` — новые участники будут принимать новую версию.

Что закон требует от вас как от оператора персональных данных (по 152-ФЗ):

1. **Отвечать на обращения в течение 10 рабочих дней.** Они приходят в «Админ-панель» → «Отзывы» с пометкой «Обращение к
   владельцу»; там же кнопка «Ответить».
2. **Уведомление Роскомнадзора о трансграничной передаче** (ст. 12) — только для Telegram: вход через бота и напоминания
   идут через серверы Telegram за рубежом. Бесплатное онлайн-уведомление: https://pd.rkn.gov.ru → вход через Госуслуги →
   «Уведомление о намерении осуществлять трансграничную передачу». Получатель — Telegram Messenger Inc., цель — «вход и
   напоминания участникам по их просьбе», данные — Telegram id, имя и текст сообщений бота. Вход через Яндекс ID
   трансграничной передачи не создаёт: ООО «Яндекс» и Yandex Cloud — в России.
3. **Общее уведомление об обработке ПД** (ст. 22), по-видимому, не нужно: данные получены для исполнения соглашения с самим
   участником и третьим лицам без его согласия не передаются (п. 2 ч. 2 ст. 22).

Это прочтение закона Claude, а не заключение юриста.

## Что делает развёртывание (для любопытных)

`.github/workflows/club.yml` → `server/tools/deploy.js`. Повторный запуск безопасен: что уже есть — не пересоздаётся.

1. Проверки: `server/test/*` и логика клуба `club/tests/lib.test.js`.
2. Ставит программу `yc` и входит ключом из `YC_SA_KEY`.
3. Сервисные аккаунты `club-fn` (функции: база и сейф) и `club-gw` (шлюз и таймер: запуск функций).
4. База `club` (YDB serverless, ru-central1) и таблицы.
5. Сейф `club-secrets` (Lockbox): ключ базы, токен бота, секрет вебхука, Client secret Яндекс ID. Значения не выводятся
   ни в журнал, ни на диск.
6. Функции `nachert-club-api` и `nachert-club-remind`, шлюз `nachert-club` по `server/apigw.yaml`, новая версия кода
   с настройками (адрес, имя бота, владелец, ClientID, адрес страницы клуба) и ключами из сейфа.
7. Таймер напоминаний (каждые 15 минут), вебхук бота и команды — с сервера GitHub, ему Telegram доступен.
8. Записывает адрес API в `club/config.js` и CSP `club/index.html` — чтобы страница на nachert1830.ru знала, куда
   обращаться. Если адрес поменялся, делает коммит в ту же ветку.

Ссылку для входа владельца без Яндекса и Telegram можно получить и с компьютера с программой `yc`:
`node server/tools/login.js` (запасной путь).

Локальная эмуляция без облака: `node server/dev.js --site-port=8788` → `http://localhost:8788/club/` (как на сайте) или
`http://localhost:8787/`; Яндекс ID и бот там поддельные, владелец — логин Яндекса `owner` или Telegram id `1000001`.
