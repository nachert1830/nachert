# Проверка сайта

`node tests/run.js` — полная проверка (её же запускает GitHub после каждого изменения, см. вкладку Actions).

| Файл | Что проверяет |
|---|---|
| `geometry.js` | Каждый чертёж восстанавливается в 3D по проекциям A′, A″. Проверяются линии связи (в том числе π₃), принадлежность и деление отрезка в одном отношении, конкурирующие точки, видимость (штрих — точку закрывает плоскость, которая ближе), размеры и углы на чертеже, утверждения в тексте шагов (∥, ⊥, ∈, «пересекаются/скрещиваются», \|AB\|, координаты), одна точка — одно имя. |
| `render.js` | Чертежи рисуются в ширину телефона: подписи не налезают друг на друга и на точки, не выходят за край. |
| `mutate.js` | Проверка проверки: в настоящие чертежи подсаживаются ошибки (разрыв линии связи, перепутанные подписи, неверное число) и считается, сколько поймано. |
| `theory.js` | Факты курса и шаблоны их неверных формулировок; верные ответы тестов не должны совпадать с шаблоном ошибки. |
| `oracle.js` | Оракул: для 40 задач условие записано геометрически («K ∈ a и AK ⊥ a», «O равноудалена от сторон»), ответ на чертеже проверяется линейной алгеброй — независимо от того, как он построен. Углы в тексте ответа сверяются с вычисленными. |
| `random.js`, `random-run.js` | Случайные варианты: исходные данные каждой задачи искажаются (равные числа — одинаково, нули остаются нулями), задача строится заново и проходит 3D-проверку и оракул. Верный метод верен на любых данных; подогнанная точка или число, набранное руками, дают противоречие. `node tests/random-run.js --seeds=100` — отдельный прогон. |
| `gen-check.js`, `gym.js` | Тренажёр (#/ng/check/gym). Генератор вариантов на сайте ищет блоки задач так же, как эталонный разбор acorn; список задач для генератора (GEN_OK) пересчитывается: вариант должен проходить проверку, а числа в тексте — меняться вместе с данными. Каждый режим проверяется нажатиями: «построй сам» принимает верный ответ и отклоняет неверный, «найди ошибку» засчитывает нажатие на ошибку и не засчитывает мимо. Скрытые функции: окно «3D к задачам» открывается и листает шаги. |
| `mastery.js` | Мастерство (docs/mastery.md, за флагами владельца): интервалы повторения на синтетических попытках, миграция уровней из тетради, один сид — один состав забега, код переноса прогресса (экспорт → импорт), без согласия нет ни одного вызова `ym`, лента — блоки по 5 карточек одного навыка и пауза после каждой 10-й, заморозка серии, уровни 2 → 3 → 4 и падение на шаг; новые страницы на 360 px; забег проходится нажатиями до итогов. |
| `run.js` | Всё вместе + обход всех страниц на экране телефона (ошибки, горизонтальная прокрутка) и прохождение каждой задачи до ответа. |
| `baseline.json` | Случаи «проверить», разобранные вручную, с объяснением, почему это не ошибка. |
