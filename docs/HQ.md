# Штаб владельца: мысли → задачи → сайт

Адрес: **nachert1830.ru/lk/hq/** (кнопка «Штаб ↗» в пульте `me/`). Вход — тот же, что в кабинете; Штаб открывается только владельцу (роль admin).

## Конвейер

| Шаг | Сотрудник (по умолчанию) | Что делает |
|---|---|---|
| Диктовка | браузер (бесплатно) / Стенограф — `openai/gpt-4o-transcribe` | голос → текст; длинный монолог — «Запись файлом», куски по 4 минуты |
| Разбор | Аналитик — Gemini Flash | стратегия, цели, задачи, идеи, балабольство → карта со связями |
| ТЗ | Продакт — Claude Sonnet 5.5 | диалог по задаче, ТЗ с критериями готовности, разбиение на подзадачи |
| Назначение | Диспетчер — Claude Haiku 5.5 | вид (код / текст / картинка / исследование) × сложность → исполнитель из штата |
| Исполнение | штат (таблица в «Сотрудниках») | текст и исследование — сразу в Штабе; картинка — файл в `img/hq/`; код — Цех |
| Проверка | Ревизор — Claude Sonnet 5.5 | сверяет результат с ТЗ |

Любого сотрудника можно сменить: на каждом шаге (вкладка «Сотрудники»), в каждой задаче (список «Исполнитель») и своей моделью
из каталога ProxyAPI («+ Своя модель»). Каталог и цены — `server/lib/hq/roster.js`; модели с пометкой «проверить» — имена из каталога
ProxyAPI, которые ещё не вызывались: если ProxyAPI ответит «нет такой модели», имя меняется там же.

## Цех (задачи кода) — `.github/workflows/hq-work.yml`

1. Штаб создаёт Issue с ТЗ (без монолога и переписки) и метками `исп:<модель>`, `цех`, `автовыкатка`.
2. Исполнитель (`tools/hq-agent.js`) правит код в ветке `hq/issue-N`. Файлов целиком модели не отдаёт: карта проекта и оглавление
   `index.html` с номерами строк (~6 тыс. токенов вместо ~1 млн), поиск, чтение кусками по ≤ 200 строк, правки блоками. У Claude включён
   кэш (формат Anthropic Messages): повторное чтение переписки стоит ~5 % цены.
3. Быстрые тесты (`tests/run.js --quick`). Красные — задача уходит сильнее: DeepSeek V3.2 → DeepSeek V4 Pro → Sonnet → Opus (не больше 3 попыток).
4. Зелёные — PR, Ревизор сверяет дифф с ТЗ; с автовыкаткой и полным прогоном тестов — слияние в `main`. Без зелёных тестов в `main` не попадает ничего.
5. Отчёт и стоимость — комментарием в Issue; Штаб подтягивает статусы («↻ Обновить статусы», сам — раз в минуту).

Метки «в работу» (старая страница `/ceo/`) и «ai-task» обрабатывает тот же Цех. Прежние `company-work.yml` (вливал в `main` при красных
тестах) и `ai-task.yml` удалены.

## Деньги

Все модели — через один ключ ProxyAPI (`PROXYAPI_KEY`). Штаб считает стоимость каждого вызова по токенам (цена производителя × курс
ProxyAPI, по умолчанию 110 ₽/$ — это оценка, точная сумма — в кабинете ProxyAPI) и останавливается на потолке месяца (по умолчанию
1000 ₽, меняется в «Сотрудниках»). Дополнительно можно задать бюджет самому ключу в кабинете ProxyAPI.

## Хранение

Монологи, карта и переписка с продактом — закрытая база YDB (таблицы `club_hqdumps`, `club_hqnodes`, настройки — `club_config`/`hq`).
В публичный GitHub уходят только ТЗ задач кода и картинки.

## Запуск (один раз)

1. Секрет GitHub `GH_HQ_TOKEN` — токен с правами Issues и Contents (чтение и запись) на этот репозиторий. Если его нет, берётся `GH_CEO_TOKEN`.
2. Секрет `PROXYAPI_KEY` уже есть (сканер, Цех).
3. Actions → «Личный кабинет — развёртывание в Yandex Cloud» (club.yml): создаст таблицы Штаба и передаст ключи функции.

Тесты: `cd server && node --test test/hq.test.js` (маршруты, бюджет, Цех, распознавание речи — с поддельными ProxyAPI и GitHub).
