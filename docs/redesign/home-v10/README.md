## Что решил владелец (по шагам)

1. **Основа — чёрно-белая.** Светлая тема — белый фон, тёмная — чёрный. Синий не использовать.
2. **Акцент — оранжевый логотипа `#FA4B00`.** Только точечно: кнопка «Найти», выбранная вкладка, «Поделиться».
3. **Логотип** — тот же, что на сайте (белый круг + красное кольцо `#e8392b`), но на **чёрном** квадрате.
4. **Минимализм, но с цветом:** вся сочность — в плашках и плитках, фон простой. Без градиентов и свечений
   (пробовали — «перегружено»), но и не бледно (пробовали подкрашенные плитки — «скудно»).
5. **Порядок главной:** две верхние плашки → поиск → карточка «Просмотры + Владелец» → разделы двумя столбцами
   (слева Начерт, справа Инж. графика) → плавающее нижнее меню.
6. **Верхние плашки** — сплошной цвет, белый линейный рисунок (гиперболоид из образующих; тело с вырезом, грани
   выреза жёлтые). Вся плашка — кнопка, кнопок «Смотреть/Открыть» нет.
7. **Поиск — опорная точка, «центр масс»** (как счёт в банковском приложении): инверсный блок — чёрный в светлой
   теме, белый в тёмной; крупный заголовок, переключатель «Везде / Начерт / Инж. графика», поле, оранжевая «Найти».
8. **Карточка владельца:** «Просмотров» + крупное число, «Владелец · Андрей Матханов» (слово «владелец сайта» не писать),
   яркая оранжевая кнопка «Поделиться» с подписью. Обособленная, с воздухом. Не банковская карта.
9. **Плитки разделов** — сплошные яркие цвета (палитра: синий, фиолетовый, малиновый, янтарный, зелёный, оранжевый,
   голубой, графит), разной высоты как в «Сервисах» Т-Банка. Картинки — **технические рисунки по смыслу раздела**
   белыми линиями (эпюр AB, пересечение конуса и цилиндра, циферблат, плоскости π₁ π₂, три вида, деталь с вырезом,
   куб с сечением, основная надпись). Не «детские предметы» и не абстрактные кружки.
10. **Нижнее меню** — плавающая капсула; невыбранные вкладки — круглые кнопки со значком, выбранная раскрывается
    в оранжевую «таблетку» со значком и подписью.

## Что ещё не решено / дальше

- Цвета плиток по разделам — окончательно не утверждены (владелец хочет свободу выбирать цвет под задачу).
- Шрифт заголовков, компьютерная версия главной, остальные страницы в том же стиле.
- Перенос на сайт — только по команде владельца. Уже есть механизм пробного режима: `?new=1` включает новую
  главную и нижнее меню только у того, кто открыл ссылку (`window.NEWUI`, класс `.nu` на `<html>`), `?new=0` — обратно.
  В ветке он содержит **предыдущий** шаг (белый/чёрный + оранжевый, плитки с объёмными предметами) — его нужно
  обновить под этот макет. Перед вливанием в `main` — полный прогон `node tests/run.js --quick`.
