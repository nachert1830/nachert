# Экран «ДЗ»: выбор своего задания колодой карточек — макет (19 ноября 2026)

На сайт **не выкатывалось**, `main` не тронут. Стиль — как у макета главной v10 (ветка `claude/compassionate-goodall-cacru3`,
`docs/redesign/home-v10/`): белый/чёрный фон, сплошной цвет карточек, белые технические рисунки, оранжевый акцент `#FA4B00`.

- `mockup.html` — живой макет: открыть в браузере. Слева: тема, ползунок «какой сегодня день» (проверить, какое ДЗ
  считается актуальным), отклик при листании (вибрация / звук щелчка).
- `mockup.jpg` — скриншот.

## Как устроено

1. **Колода по сроку сдачи.** Все ДЗ обоих предметов в одном ряду по дате: прошедшие уезжают вверх и лежат стопкой
   полосок (видно предмет и «было до …»), следующие — снизу, видна верхушка следующей карточки.
2. **По умолчанию — актуальное:** ближайшее ДЗ, срок которого ещё не прошёл. Метка «● Сейчас · до пт, 27 нояб».
   Кнопка-прицел справа вверху загорается оранжевым, когда ушёл от актуального, и возвращает к нему.
3. **Листание — обычная прокрутка пальцем с «защёлкой»** на каждой карточке (CSS scroll-snap, инерция системная).
   На компьютере — колесо, перетаскивание мышью, стрелки ↑/↓.
4. **Щелчок на каждую карточку:** `navigator.vibrate(7)` (Android/Chrome) + системный тактильный отклик iOS 18+
   (скрытый `<input type="checkbox" switch>` — Safari даёт «тик» при его переключении). На компьютере вибрации нет —
   можно включить звук щелчка (Web Audio).
5. **Главный визуальный элемент — внизу карточки:** слово «Задание» и огромная цифра номера, обрезанная нижним
   краем (как «March / April» в референсе). Над ними — «Вариант 17», вверху — предмет и срок, тема, рисунок по смыслу ДЗ.
6. **Нажать на верхнюю карточку** — снизу выезжает лист: что внутри (разбор по шагам, чистовик, черновик, как решать,
   ошибки и защита) и оранжевая кнопка «Открыть мой вариант 17». Нажать на полоску в стопке — пролистать к ней.
7. Переключатель **Все / Начерт / Инж. графика**; «Вариант 17 ⌄» — сменить номер варианта (один на все ДЗ, как на сайте).

## Что не решено

- **Сроки сдачи** в макете черновые (недели семестра, пятница недели; начало семестра — пн 31 авг 2026, как `RKS`
  на сайте). В коде сайта сроков ДЗ нет — нужно вписать по плану кафедры (лучше в реестр: `DZR.def('ng4',{week:13})`),
  а с группой из кабинета — точный день занятия.
- Цвета карточек по заданиям — предложение, не утверждены.
- «Сдано» — отметка, чтобы сданное ДЗ не считалось актуальным даже до срока, — пока нет.
- Перенос на сайт — только по команде владельца: экран `#/dz` в пробном режиме `?new=1`, данные — из `DZR.list()`.
