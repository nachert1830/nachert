## Решения владельца
1. **Шапка:** логотип · **анимированный тумблер «Начерт / Инж. графика»** · справа **«Войти»** (оранжевая) или кружок аккаунта.
   Тумблер — бегунок с пружиной, можно нажать или потянуть пальцем; содержимое уезжает в сторону переключения; щелчок-вибрация.
2. **Тумблер переключает** две верхние плашки и плитки разделов (в один предмет, два столбца), пункт меню «РК» ↔ «Учиться».
   Поиск и карточка просмотров от предмета не зависят.
3. **Верхние плашки:** слева — главная фишка предмета, справа — ДЗ. Гость видит ДЗ «по плану» (следующее по очереди),
   вошедший — своё: «вариант 17 · до чт, 26 нояб».
4. **После поиска — плашка «Добавь Начерт как приложение».** Свайп влево — три шага инструкции (большая цифра шага, как на
   карточках ДЗ), точки внизу, щелчок на каждый слайд. Шаги под систему: iPhone (Поделиться → На экран «Домой» → Добавить),
   Android (⋮ → Установить приложение → Установить). Если браузер даёт системную установку (`beforeinstallprompt`) —
   на первом слайде кнопка «Установить». Крестик прячет плашку. В установленном приложении плашки нет.
5. **Остальное убрано:** «Продолжить», «План на сегодня», «До РК», строка «Войди…» — не нужны.
6. **Вход — всплывающим окном снизу** в нужные моменты (Яндекс ID, почта, «Не сейчас»). В макете: «Войти» в шапке
   и нажатие гостя на плашку ДЗ. Кандидаты на другие моменты: открыл второй вариант ДЗ, вписал номер варианта,
   вернулся на сайт третий раз, перед РК. Не чаще раза в несколько дней после «Не сейчас».
