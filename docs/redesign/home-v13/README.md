## Изменения относительно v12 (по замечаниям владельца)
1. **«Добавь иконку на рабочий стол» — ползунок**, как «сдвиньте, чтобы ответить»: иконка Начерта тянется вправо,
   за ней оранжевая заливка, надпись «сдвинь — покажу как» с бегущим бликом, щелчки по пути. Дотянул до конца —
   снизу выезжает инструкция: переключатель iPhone / Android, три цветных шага с большой цифрой, «Понятно»
   (или «Установить сразу», если браузер умеет ставить сам). Отпустил раньше — ползунок пружинит назад. Тап по иконке —
   тоже открывает инструкцию.
2. **Экран предмета — только суть:** название, текущее ДЗ, плитки разделов. Списка и подвала под ними больше нет.
3. **Нижней панели нет.** Главная — общая, в предмет ведёт тумблер наверху, назад — логотип, который в предмете
   превращается в стрелку «‹». Пункты панели (Тетрадь, ДЗ, РК, Теория) и так есть плитками и на главной, и в предмете.
4. **Плитки и поиск ведут на настоящий сайт** (новая вкладка): `#/ng/tasks`, `#/ig/wb`, `#/ng/rk2`, `#/dz`, `#/ng4` …
   Поиск: число → задача тетради выбранного предмета, «дз …» → экран ДЗ.
