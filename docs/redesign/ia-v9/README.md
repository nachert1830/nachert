# Архитектура v9 — что где и кому что показываем (19 ноября 2026, черновик на решение)

Продолжает `docs/IA.md` (v8). Сначала раскладка содержимого, дизайн — потом поверх неё. На сайт не выкатывалось.
Схемы экранов — `ia-v9.html` (открыть в браузере). Опубликованная копия (приватная): https://claude.ai/artifact/9HcfbrZXe6VKmM5NWiQPph

## Три состояния пользователя
- **Гость** — ДЗ «по очереди» (следующее по общему плану семестра), сроки — недели семестра.
- **Гость с вариантом** (`nch2_dzvar`) — то же, но карточки открывают сразу его вариант.
- **Студент в кабинете** (`lk_profile` + группа) — ближайшее несданное ДЗ его предметов, срок — день занятия группы
  (`lk/data/groups.json`), отметки `lk_done`, точный день РК.

## Главная (сверху вниз)
Шапка (лого · Спросить · Войти/аватар) → «ДЗ сейчас» + «До РК» → [гость] «Войди — будут сроки группы» → поиск →
«Продолжить» (`nch2_last`) → «План на сегодня» (гость — повторение `#/ng/day`; студент — шаг плана из кабинета) →
[в браузере, не установлено] «Установить как приложение» (`#/install`; «не сейчас» — на 14 дней; у студента — в профиле) →
«Просмотры + Поделиться» → переключатель предмета + живые плитки (Тетрадь N из 89, 3D-эпюр, РК, Теория) → нижнее меню.

## Начерт и ИГ
Расписание: из 303 групп 140 — оба предмета, 94 — только ИГ, 69 — только начерт.
- Один выбор «мой предмет» на весь сайт (`nch2_course`, новый); меню одинаковое, меняется содержимое (у ИГ «РК» → «Учиться»).
- Студенту предмет задаёт группа: один предмет — переключатель скрыт везде.
- Переключатель: на главной над плитками и капсулой в шапке Тетради/РК/Теории; в нижнем меню нет.
- Не зависят от предмета: поиск, экран ДЗ (колода по сроку), плашки «ДЗ сейчас» и «До РК».
- Гость: по умолчанию начерт, не спрашиваем; ссылка на раздел ИГ переключает предмет.

## Кабинет: сайт — «что делать», кабинет — «про меня»
Знакомство (имя → группа → вариант) · **Сегодня** (ближайшая сдача, план по дням, «сдано», следующее занятие) ·
**Сдачи** (семестр по неделям, отметки, модули) · **Скан** (пока скрыт) · **Профиль** (группа, вариант, вход, напоминания,
установить приложение, тема, копия, выход). Вход — аватар в шапке сайта.
