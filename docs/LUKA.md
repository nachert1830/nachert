# Лука — ИИ-агент на чертеже

Пингвин в углу чертежа (копия `/new/`, файлы `new/luka.js`, `new/luka.css`, `new/luka-lib.json`). Объясняет шаг разбора, показывает
на чертеже, открывает 3D, отвечает на свой вопрос студента. Главное правило — **дёшево**: почти всё отвечается без модели.

## Как Лука отвечает

| Ступень | Что | Цена |
|---|---|---|
| 1. Кнопки | ответы из данных шага: решатель (шаг, «почему так», намёк, числа, «проверь себя»), словарь `GLOSS`, ошибки методики ДЗ, 3D | 0 |
| 2. Свой вопрос | разборщик в браузере: нормализация, синонимы, корни слов, тип вопроса, точки и шаг → уверенность 0…1 | 0 |
| 3. Сомнение (0,3–0,55) | «Ты про это?» — 2–3 ближайших вопроса кнопками | 0 |
| 4. Не знаю (< 0,3) | наставник на сервере `/api/tutor/chat` (режим `explain`, ответ сверяется с решением); вне ДЗ или без входа — «пока не знаю, записал» | ~0,1–1 ₽ |

Сильная заготовка из `luka-lib.json` (≥ 2 общих корня) важнее словаря: на «как получаются проекции точки» — развёрнутый ответ, а не определение.

## Где стоит

Начерт — плеер разбора (`PLAYER.mount`, опция `luka`): ДЗ №4–5 (`{dz,n}`), тетрадь с 68-й задачи (`{task}`). ИГ — плеер шагов (`buildBlock`, опция `luka` из `partPage`): ДЗ №5–6, тетрадь с 7-го задания (`{task:"ig7"}`); показ — подсветка подписей точек шага (1″, 1′, 1‴). Только последние задания семестра — так решил автор.

## Как Лука учится сам

1. Вопрос, на который не нашлось заготовки (ступень 4), и каждый 👎 уходят на сервер: `POST /api/luka/miss` — место (`ng4:13:3`,
   `task:70:2`), текст (почта и телефоны вырезаются), уверенность. Без имени и аккаунта. Таблица `lukamiss`, 90 дней (`server/lib/luka.js`).
2. Раз в сутки запускается сессия обучения (запланированная задача Claude). Она читает журнал `GET /api/luka/inbox?days=2`
   (заголовок `x-luka-key` подставляет среда), дописывает `new/luka-lib.json` и проверяет копию.
3. Пользователь в этом не участвует.

### Инструкция для сессии обучения

1. `git fetch origin claude/nifty-curie-j6ymiv && git checkout claude/nifty-curie-j6ymiv`.
2. `curl -s "$(sed -n "s/.*CLUB_API='\(.*\)'.*/\1/p" lk/config.js)/api/luka/inbox?days=2"` — заголовок ключа подставит среда.
   Ответ 403 или нет сети — записать в итог «журнал недоступен» и закончить, ничего не меняя.
3. Сгруппировать вопросы по смыслу и месту. Для групп, где ≥ 2 похожих вопроса или есть 👎:
   - вопрос про термин — проверить, есть ли он в `GLOSS` (`new/index.html`), если нет — заготовка с `intent: "term"`;
   - вопрос про шаг — заготовка с `where` этого места (`ng4:*:3` — шаг 3 всех вариантов ДЗ №4, если шаг тот же по смыслу);
   - общий вопрос («не понимаю смысл», «как строить точку») — `where: "*"`;
   - новые слова студентов (сленг, опечатки) — в `syn`;
   - 👎 на заготовку — переписать её ответ короче и понятнее.
4. Ответы — только верные по предмету, коротко (2–4 предложения), на «ты», без наводящих вопросов. Не выдумывать числа: числа
   и точки есть только в решателе.
5. `node tests/new-copy.js` — должно быть «ошибок нет». Коммит «Лука: заготовки по журналу ДД.ММ», пуш в ту же ветку.
6. Не трогать ничего, кроме `new/luka-lib.json` (и, если нужно, порогов `HI`/`MID` в `new/luka.js` по доле 👎).

## Включение журнала (один раз)

1. Придумать пароль журнала и положить его в секреты репозитория как `LUKA_KEY`.
2. Тот же пароль — в сетевой секрет среды Claude для адреса API (заголовок `x-luka-key`).
3. Запустить «Личный кабинет — развёртывание» (`.github/workflows/club.yml`) — появится таблица `lukamiss` и маршруты.
