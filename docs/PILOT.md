# Пилот: измеряем, учит ли «Начерт»

Автоматическая проверка доказывает, что чертежи на сайте верны. Учит ли сайт — отдельный вопрос, и на него отвечает
только эксперимент. Этот документ — готовый протокол; всё, что нужно на стороне сайта, уже встроено.

## Вопрос и гипотеза

**Вопрос:** решают ли студенты, которые занимаются с «Начертом», задачи РК и ДЗ лучше тех, кто занимается без него?
**Гипотеза H₁:** средний балл РК-1 в группе с сайтом выше, чем в контрольной, при равном входном уровне.
**Вторичные исходы:** доля ДЗ №2–3, сданных с первого раза; число ошибок, найденных «Сверь свой лист»; время до сдачи.

## Дизайн

- **Кластерная рандомизация по учебным группам**, не по студентам: внутри одной группы сайт неизбежно «перетекает»
  к соседям. Группы одного потока делятся жребием на две ветви; преподаватель в каждой паре ветвей — один и тот же,
  чтобы различие не объяснялось преподавателем.
- **Входной срез** (неделя 1): 10 задач уровня ДЗ №1 на бумаге, 20 минут, одинаково в обеих ветвях.
- **Вмешательство** (недели 2–8): ветвь «сайт» получает ссылку с меткой группы и задание пройти разборы к каждому
  семинару; контрольная ветвь — те же задачи в рабочей тетради без сайта (после пилота сайт открывается всем).
- **Исход** — баллы РК-1 и результаты защиты ДЗ №2–3 из ведомости, обезличенные: преподаватель передаёт только
  код группы и балл, без фамилий.

## Размер выборки

Для эффекта d = 0,4 (типичный для интерактивных тренажёров), α = 0,05, мощности 0,8 нужно ≈ 100 студентов на ветвь;
с поправкой на кластеры (ICC ≈ 0,05, группа ≈ 25 человек, эффект дизайна 1 + 24·0,05 = 2,2) — **≈ 9 групп на ветвь**.
Один поток первого курса МГТУ закрывает это с запасом.

## Что делает сайт

- **Метка группы.** Ссылка `https://nachert1830.ru/?pilot=g07` запоминает код группы `g07` в браузере (только код,
  1–8 латинских букв и цифр). `?pilot=off` — убрать метку.
- **Учебные события без cookie** (`docs/ANALYTICS.md`): открыт разбор, пройден до ответа, режим «Смотрю» / «Решаю сам»,
  ответ в тренажёре верный или нет, проверен лист ДЗ. С меткой путь события начинается с `g-g07/`, например
  `ev/g-g07/task_done/try/46`. GoatCounter хранит только число отметок по пути — без IP, без cookie, без имени.
  Это даёт **дозу вмешательства по группам**: сколько разборов и в каком режиме прошла каждая группа.
- События уходят от всех, кроме нажавших «Нет» в уведомлении о cookie, поэтому выборка не смещена к согласившимся.

## Анализ

1. Сравнение баллов РК-1 между ветвями — смешанная модель: балл ~ ветвь + входной срез + (1 | группа).
2. Доза — ответ: связь числа пройденных разборов в группе (из GoatCounter) со средним баллом группы.
3. Заранее объявленные исходы и модель фиксируются в этом файле **до** начала пилота (коммит с датой — отметка
   предрегистрации).

## Этика и данные

Персональные данные сайт не собирает: метка — код группы, исходы — обезличенная ведомость от преподавателя.
Участие ветви «сайт» добровольное; контрольная ветвь получает доступ сразу после РК-1.
