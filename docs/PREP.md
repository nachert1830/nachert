# Подготовка перед большим заданием (ДЗ, РК)

Зачем: у студента в плане есть часы самостоятельной подготовки. Перед ДЗ №4, ДЗ №5, РК3 — не сразу разбор своего
варианта, а короткая лестница навыков: каждый навык — отдельно, на маленьком чертеже, с точным построением.
Сейчас готово: **ДЗ №4** (`#/ng4/prep`, данные — `dz/ng/4/prep.js`). Следующие — ДЗ №5 и РК3 по тому же шаблону.

## Как устроен шаг

Один шаг = один навык. Два экрана:

1. **Правило + мини-чертёж** (`#/ng4/prep/3`). Правило — 1–2 фразы, главное выделено. Мини-задача идёт в обычном плеере
   по 3–5 шагам: построение «как на листе» (посредник → сечения → точки), 3D к каждому шагу.
2. **Проверь себя** (`#/ng4/prep/3/q`). Один вопрос на суть (4 варианта, объяснение после ответа) → «Где ошибаются»
   (одна строка) → «Закрепи в тетради» (задачи тетради с разбором) → следующий шаг.
   Верный ответ = шаг пройден (прогресс `prep_<id>` на устройстве, счётчик на вкладке «Подготовка»).

Путь (`#/ng4/prep`): шкала, «твой вариант N — нужны шаги …» (по типу варианта), список шагов, в конце — «Мой вариант N».
На странице варианта, пока подготовка не пройдена, — строка «Не начинай с ответа. Подготовка: k из N».

## Правила содержания

- **От малого к большому.** Первый шаг — то, без чего нельзя второй (точка на поверхности → сечение → посредник →
  крайние точки → видимость → проецирующая поверхность → сферы).
- **Коротко.** Правило ≤ 2 фраз, текст шага плеера ≤ 3 фраз, ошибка — 1 строка. Длинное объяснение не нужно: его
  заменяет чертёж по шагам.
- **Точно.** Каждая точка мини-задачи — построением (окружность ∩ окружность, хорда ∩ хорда), а не подбором по сетке;
  крайние точки — плоскостью симметрии (или её поворотом), а не «самым верхним посредником».
- **Одна сцена на несколько шагов.** В ДЗ №4 шаги 2–5 идут на одних и тех же конусе и сфере — студент видит, как
  растёт одно решение.
- **Привязка к варианту.** `types` шага — для каких типов он нужен; `plan[тип]` — какая пара тел каким шагом решается.

## Данные (`DZR.def(id, {prep:{…}})`)

| Поле | Что |
|---|---|
| `title`, `lead` | заголовок и одна строка о пути |
| `steps[]` | `{id, t, sub, rule, task(), check:{q,o,c,e}, trap, wb:[[№,подпись]], types}` |
| `task()` | задача в формате плеера (`given`, `steps[{t,d,why,add}]`, `ans`, `surf3` для 3D) или с `parts`; `cert()` — самопроверка |
| `typeName`, `plan` | подписи типов вариантов и «что каким шагом» для своего варианта |

Сайт рисует путь и шаги сам (`dzPrep` в `index.html`) для любого ДЗ, у которого есть `prep`: для ДЗ №5 достаточно
создать `dz/ng/5/prep.js` и подключить его после решателя.

## Проверка

`node tests/prep.js` (входит в `tests/run.js`): каждая точка мини-задач лежит на всех своих поверхностях
(|f| < 0,01 мм), высшая и низшая точки сверяются с линией, найденной заново перебором горизонтальных плоскостей,
у сфер-посредников есть точки, R<sub>min</sub> — вписанная сфера; экраны — плеер доходит до вопроса, неверный ответ не
засчитывается, верный засчитывается, нет горизонтальной прокрутки на телефоне.

## Черновик для ДЗ №5 и РК3

- **ДЗ №5 (прямая и поверхность):** точка на поверхности → плоскость через прямую (проецирующая) → сечение конуса
  плоскостью через вершину (образующие) → сечение цилиндра плоскостью ∥ образующим → точки входа и выхода, видимость
  прямой → касательная плоскость и нормаль через h и f.
- **РК3:** по типам задач билета, как «РК2 за 9 шагов».
