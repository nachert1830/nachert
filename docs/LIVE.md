# Онлайн-разборы: запись, бот, форма, страница

Бесплатные онлайн-разборы по начерталке (РК2, ДЗ) в Яндекс Телемосте. Это отдельная личная деятельность автора,
к сайту не относится; сайт бесплатный.

## Из чего состоит

| Часть | Где | Что делает |
|---|---|---|
| Карточка на главной | `index.html`, модуль `PROMO` | До 13.11 — «РК2 завтра?», с 14.11 — «ДЗ 2–3 не идёт?». Кнопка «Я приду →» — бот, ссылка «или через форму» — Яндекс Форма |
| Страница `#/live` | `index.html`, `viewLive` | Как записаться, как проходит, план «РК2 за 9 шагов» (только типы задач, без билетов), какие данные и зачем |
| Бот записи | `server/livebot/` | Запись кнопкой, напоминание за 2 часа, ссылка за 15 минут, «Помогло?» после, удаление данных |
| Яндекс Форма | forms.yandex.ru (создаёт владелец) | Для тех, у кого нет Telegram |

Две строки, которые надо заполнить в `index.html` (модуль `PROMO`, одно место на весь сайт):

```js
const PROMO_BOT='[ИМЯ_БОТА]';            // имя бота без @, например nachert_live_bot
const PROMO_FORM='[ССЫЛКА_НА_ФОРМУ]';    // https://forms.yandex.ru/u/…
```

Статистика нажатий (GoatCounter, без cookie): `ev/promo/rk2`, `ev/promo/dz` — кнопка бота на карточке,
`ev/promo/form` — форма, `ev/promo/close` — крестик, `ev/promo/live-bot`, `ev/promo/live-form` — кнопки на `#/live`.

## 1. Бот

1. В Telegram — @BotFather → `/newbot` → имя «Начерт · эфиры», username, например `nachert_live_bot`. Сохрани токен.
2. Там же: `/setdescription` — «Запись на бесплатные онлайн-разборы по начерталке»; `/setcommands`:
   ```
   start - записаться на эфир
   my - мои записи и ссылка
   delete - удалить мои данные
   ```
3. Узнай свой Telegram ID (например, у @userinfobot) — это `LIVEBOT_ADMINS`.
4. Запусти бота на сервере (раздел 2) и напиши ему: `/admin` — список команд владельца.

Команды владельца (видит и может только он):

```
/add 10.11 20:00 РК2: типы задач    — добавить эфир (время московское)
/link https://telemost.yandex.ru/j/…  — ссылка на ближайший эфир (или /link <id> <ссылка>)
/list                                 — эфиры, сколько записалось, «помогло»
/who                                  — кто записан на ближайший
/say Начинаем через 5 минут          — написать всем записанным
/del <id>                             — отменить эфир (записанным придёт сообщение)
```

Если за 15 минут до начала ссылки нет, бот напишет владельцу «⚠️ ссылки нет» и разошлёт её, как только придёт `/link`.
Вопросы, которые ученики пишут боту текстом, пересылаются владельцу.

Число записавшихся видно только владельцу в `/list` — ни на сайте, ни у бота публичного счётчика нет.

## 2. Где запускать бота — свой VPS в России

Почему не Яндекс Облако: из облачных функций исходящие запросы к `api.telegram.org` иногда не проходят
(см. комментарий в `server/lib/telegram.js`), а напоминания и ссылку бот отправляет сам. Почему VPS в России:
бот хранит имя в Telegram и номер чата — это персональные данные граждан РФ, их базы должны находиться в России
(ч. 5 ст. 18 152-ФЗ; по той же причине на сайте выключен Google Analytics).

Бот работает в режиме long polling: сам забирает обновления у Telegram. Домен, SSL и вебхук не нужны.

1. Возьми самый маленький VPS у российского хостинга (1 vCPU, 1 ГБ, Ubuntu 24.04; обычно 200–400 ₽ в месяц;
   удобно, если оплата почасовая — можно сначала проверить).
2. Сразу проверь, что Telegram оттуда открывается:
   ```
   curl -sS https://api.telegram.org | head -c 100
   ```
   Пришёл любой ответ (даже 404) — всё в порядке. Таймаут — бери другой хостинг.
3. Установи Node.js 22 и положи код:
   ```
   curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash - && sudo apt-get install -y nodejs git
   sudo useradd -r -m -d /opt/livebot livebot
   sudo -u livebot git clone --depth 1 https://github.com/nachert1830/nachert /opt/livebot/nachert
   sudo install -d -o livebot -m 700 /opt/livebot/data
   ```
4. Токен и ID — в файл, который видит только root:
   ```
   sudo tee /etc/livebot.env >/dev/null <<'EOF'
   LIVEBOT_TOKEN=123456:ABC…
   LIVEBOT_ADMINS=123456789
   LIVEBOT_DATA=/opt/livebot/data/live.json
   EOF
   sudo chmod 600 /etc/livebot.env
   ```
5. Служба, которая перезапускается сама: `sudo cp /opt/livebot/nachert/server/livebot/livebot.service /etc/systemd/system/ && sudo systemctl enable --now livebot`.
   Журнал: `journalctl -u livebot -f`.
6. Обновить код: `sudo -u livebot git -C /opt/livebot/nachert pull && sudo systemctl restart livebot`.

Данные — один файл `live.json`. Через 30 дней после эфира бот сам стирает из него людей, остаются только числа.

## 3. Яндекс Форма (для тех, у кого нет Telegram)

forms.yandex.ru → «Создать форму». Коротко, три поля:

- **Название:** «Запись на бесплатный разбор по начерталке»
- **Описание:** «Разбираем типы задач по шагам, вживую в Яндекс Телемосте, 1,5 часа. Ссылку пришлём перед эфиром.»
- **Поле 1 — «Как к тебе обращаться»**, короткий текст, обязательное.
- **Поле 2 — «Куда прислать ссылку»**, короткий текст, обязательное, подсказка «почта или телефон».
- **Поле 3 — «На какой разбор»**, один из списка: «РК2», «ДЗ № 2–3». Обязательное.
- **Поле 4 — галочка**, обязательная:
  «Согласен(на), чтобы автор онлайн-разборов обрабатывал моё имя и контакт, чтобы прислать ссылку и напоминание об эфире.
  Данные удаляются через 30 дней после эфира; отозвать согласие и удалить данные можно, написав на контакт, указанный выше.»
  (В тексте согласия укажи свой контакт для отзыва — почту или Telegram.)
- **Экран после отправки:** «Записали! Ссылку пришлём перед эфиром. Есть Telegram? Бот напомнит сам: t.me/<имя_бота>»
- **Уведомления:** в настройках формы включи письма о новых ответах себе на почту.

Ответы формы хранятся в Яндексе (в России). Ссылку тем, кто записался через форму, рассылаешь сам перед эфиром;
через 30 дней удаляешь ответы в разделе «Ответы».

## 4. Перед эфиром (чек-лист)

1. В Телемосте создать встречу → `/link <ссылка>` боту (лучше за час).
2. `/list` — сколько записалось; написать тем, кто из формы.
3. Открыть план: `#/live` → «РК2 за 9 шагов»; по каждому типу — страница темы (идея, как решать, где ошибаются).
4. Демонстрация окна браузера, масштаб 125–150 %, светлая тема сайта.

## Проверка

`node --test server/test/livebot.test.js` — запись, напоминания, ссылка по кнопке, «помогло», удаление данных,
команды владельца, недоступность команд владельца остальным. Страница `#/live` и карточка — в обходе `tests/run.js`.
