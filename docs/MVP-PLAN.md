# План MVP

Этапы: ① материал → ② ядро → ③ дизайн → ④ ИИ-агент. **① и ② закрыты.** На MVP остаются только ③ и ④.

## Осталось

### ③ Дизайн
- Единый визуальный язык для программы подготовки (`#/prep`, `#/prep/ig*`), страниц ДЗ и плеера шагов.
- Цвета и токены — `docs/color-policy.md`, решения — `docs/design-decisions.md`, IA — `docs/IA.md`.
- Ядро и данные дизайн не трогает: всё рисуется из `IG3`, `PREP`, `IGS`. Проверка, что ничего не сломалось, — `node tests/run.js`.

### ④ Агент на базу
Агент ничего не решает сам: он формулирует ответ по структуре, которую даёт ядро.

| Что агенту нужно | Откуда |
|---|---|
| Контекст ученика (ДЗ, вариант, шаг, тема) | `core/tutor.js` → `context()` |
| Шаги решения с «почему» (2485 шагов) | `kb/tutor/*.json` |
| «Как строится эта дырка» (ИГ, 147 вариантов, 761 элемент) | `core/ig-explain.js` (`find`, `explain`, `say`), `kb/ig-dz.json` |
| Проверка утверждения ученика | `checkClaim` / `parseClaim` (НГ), `checkIG` / `parseIGClaim` (ИГ) |
| Подсказка без спойлера | `ladder`, `mask`, `fallback` |
| Проверка ответа модели перед показом | `lint` (числа и факты — только из базы) |
| Теория и ловушки (53 темы НГ + 67 тем ИГ) | `kernel/prep.js`, `kernel/prep-ig.js`, `kb/kb.json` |
| Целостность базы | `kb/graph.json` (Merkle-граф, 4796 узлов); `node tools/kb-graph.js --verify` |

Контракт — `docs/TUTOR-CORE.md`.
