# «Связь» — дизайн-система и концепция Начерта (v1, ноябрь 2026)

> Новый интерфейс для всего nachert1830.ru: одна система, одна навигация, светлая и тёмная темы, ИИ-наставник в центре.
> Наполнение сайта не меняется. Меняется подача.

| Файл | Что внутри |
|---|---|
| `README.md` | этот документ: исследование, принципы, компоненты, наставник, экраны, возвраты, анимации, внедрение, инновации |
| `tokens.json` | токены — источник истины (цвет обеих тем, шрифт, шкала, отступы, радиусы, движение, пружины) |
| `tokens.css` | те же токены как CSS-переменные, готовые к подключению |
| `contrast.js` | проверка контраста по WCAG 2.2: `node docs/design-system/contrast.js` (`--md` — таблица) |
| `prototype.html` | интерактивный прототип одним файлом: главная → наставник → предмет → задание → разбор → тест, профиль, план, поиск, первый заход |

Прототип открывается как обычная страница: `docs/design-system/prototype.html` (шрифты берёт из `fonts/`). Переключатель темы — в шапке,
«Меньше движения» — в профиле. Адреса экранов: `#home`, `#agent`, `#subject-ng`, `#task`, `#variant`, `#levels`, `#test`, `#me`, `#plan`,
`#search`, `#hello`.

Название системы — **«Связь»**, по линии проекционной связи: тонкой линии, которая соединяет две проекции точки и делает плоский
чертёж объёмным. Интерфейс делает то же самое: связывает задание, твой вариант, шаг, лист и наставника в одну цепочку.

## 0. Коротко

1. **Центр — наставник.** Главная начинается с поля «Задача, вариант или вопрос». Одна строка и ищет, и спрашивает: «47» открывает
   задачу, «дз 4 вариант 13» — разбор, «не понимаю замену плоскостей» — разговор. Как адресная строка Chrome: в одном поле и поиск, и вопрос.
2. **Облик наставника — «Огибающая».** Окружность, построенная из касательных. Она вращается в пространстве, и в проекции становится
   эллипсом. Задние касательные рисуются штрихом, как невидимые линии на чертеже. Образ взят прямо из предмета, без лица и без маскота.
3. **Фирменный жест — «линия дочерчивается».** Всё новое на чертеже появляется так, будто его ведут карандашом: 600 мс, по одной линии.
4. **Цвет — графит и один фирменный «Сурик».** Сурик отмечает текущее построение на чертеже, главное действие на экране и прогресс.
   Больше ярких цветов в интерфейсе нет. Остальные — смысловые: верно, ошибка, срок.
5. **Навигация 4 + 1.** Главная · Предметы · **Наставник** · План · Я, над меню — мини-панель «Сейчас делаешь», как плеер в Spotify.
   На компьютере — рейка слева и наставник, пристыкованный справа.
6. **Три функции-прорыва.** «Наставник рисует на твоём чертеже», «Рентген листа» (ошибки поверх фото твоего листа), «Защита»
   (вопросы по твоему листу, голосом). Первые две показаны в прототипе в действии, третья — первым вопросом.
7. **Позиционирование одной фразой:** «Начерт объясняет твой вариант на твоём же чертеже».

## 1. Исследование

### 1.1. Приём → откуда → почему работает → как применяем

| Приём | Откуда | Почему работает | Как у нас |
|---|---|---|---|
| Персональная главная из «полок» | Spotify Home | Узнавание быстрее поиска. Полка = готовый выбор из 4–6 вариантов (закон Хика) | Главная: «Сейчас», полка «Продолжить», предметы. Порядок зависит от сроков |
| Обложка как идентичность объекта | Spotify, Apple Music | Картинку узнают за ~13 мс (Potter, 2014), строку текста — дольше | Обложка каждого ДЗ — его настоящий вычисленный чертёж в фирменной манере: сетка, графит, одна линия Сурика |
| Мини-плеер «сейчас играет» | Spotify, YouTube Music | Незавершённое держит внимание (Зейгарник), вернуться — одно касание | Мини-панель «ДЗ №4 · вариант 13 · шаг 5 из 7» над меню на всех экранах, кроме самого разбора |
| Тёмная тема как основная | Spotify, YouTube | Вечер и ночь, OLED, меньше слепит | Обе темы спроектированы на равных. Тёмная — режим САПР: чертёж светлыми линиями на графите. Печать всегда на белом |
| Один фирменный цвет на всё действие | Spotify, Duolingo | Глаз находит главное за одну фиксацию (pop-out, Treisman) | Сурик — только главная кнопка, текущая линия построения, прогресс, активная вкладка |
| «Продолжить просмотр» с полосой прогресса | YouTube | Видно, сколько осталось, и вернуться легче (эффект цели, Hull) | Полка «Продолжить»: обложка с тонкой полосой Сурика снизу |
| Главы на таймлайне | YouTube chapters | Длинное делится на смысловые части, можно прыгнуть к нужной | Разбор варианта: шкала из 7 глав («Опорные 1, 2», «Очерк: 3, 4»…), каждая нажимается |
| Поиск понимает номер и смысл | YouTube, Google | Пользователь знает номер задачи или варианта, а не структуру сайта | «47», «дз 4 13», «вариант 13» — прямые попадания. Остальное уходит наставнику |
| Вход без порога | TikTok, VK Клипы | Ценность до регистрации, первый экран уже работает | Без входа сайт работает полностью. Вход — одна кнопка в профиле, только чтобы сохранить прогресс |
| Одно действие на весь экран | TikTok | Меньше выбора — быстрее начинаешь (Хик) | Карточка «Сейчас»: одна кнопка «Продолжить с шага 5» |
| Короткая единица контента | TikTok, Brilliant | Небольшой кусок легче начать. Нагрузка на рабочую память меньше (Sweller) | Шаг разбора — одна идея и одна новая линия на чертеже |
| Поисковая строка как начало всего | Chrome, Google | Один вход вместо меню, закон Якоба | Омнибокс в центре главной: поиск + вопрос в одной строке, рядом камера для фото листа |
| Подсказки-примеры под полем | ChatGPT, Claude, Gemini | Пустое поле пугает. Примеры показывают, что можно спросить | 4 стартера, собранные из твоего контекста: начатый шаг, ближайший срок, лист, защита |
| Видимое «думает» со статусом | Perplexity, Claude | Ожидание с объяснением кажется короче (Maister, 1985). Порог Доэрти | За 100 мс «Огибающая» ускоряется. Строка статуса: «Смотрю твой шаг 5 → Сверяю с решением варианта 13» |
| Ответ потоком | ChatGPT, Grok | Первые слова приходят за доли секунды | Текст идёт по словам. Каждое слово даёт «Огибающей» короткий импульс |
| Обезличенный живой агент | Siri, Grok, Gemini | Нет лица — нет «зловещей долины» и детскости, остаётся ощущение присутствия | «Огибающая»: геометрия вместо маскота, движение показывает состояние |
| Агент знает контекст | Cursor, Copilot, Claude Projects | Не нужно объяснять, где ты | Чип контекста «ДЗ №4 · в13 · шаг 5» в шапке разговора, сменить можно одним касанием |
| Статус-карта как символ принадлежности | American Express (Gold, Platinum) | Статус, который заработал, хочется показать (сигнальная теория) | «Штамп» в профиле — основная надпись листа по ГОСТ: статус Эскиз → Черновик → Чистовик → Эталон |
| Прозрачные уровни | Revolut Standard/Plus/Metal | Понятно, что даёт следующий уровень | Под статусом: «До Чистовика — 3 уровня на три звезды» |
| Серия без наказания | Duolingo (streak freeze), Apple Fitness (кольца) | Привычку укрепляет регулярность. Страх потерять серию выжигает (Hooked: награда, а не угроза) | «Ритм»: 3 учебных дня в неделю. Пропуск ничего не обнуляет |
| Путь уровней | Duolingo path | Видно, где ты и что дальше. Маленькие цели (goal-gradient) | Карта подготовки к ДЗ: 6 уровней, звёзды, следующий подсвечен |
| Сложное маленькими шагами с действием | Brilliant | Сначала попробуй сам, потом объяснение (generation effect, Slamecka & Graf) | Режим «Решаю сам»: новая линия скрыта, вопрос «Где окажутся 3′ и 4′?», затем «Показать шаг» |
| Проверка себя сразу | Brilliant, Anki | Вспоминание укрепляет память сильнее, чем перечитывание (Roediger & Karpicke, 2006) | Тест «где верно» после каждого уровня. «Проверь себя» в каждом шаге |
| Интервальное повторение | Anki, Duolingo | Промежутки 1 → 3 → 7 → 16 дней дают лучшее запоминание (Cepeda и др., 2008) | Навыки в профиле с датой повторения. В «Плане» на сегодня — 1–2 повторения по 3 минуты |
| Точное движение и плотность | Linear | Быстрые 150–250 мс переходы кажутся мгновенными, но направляют взгляд | Длительности 150–400 мс, пружины без лишнего отскока, отскок только на успехе |
| Пространственная память | Arc (сайдбар) | Постоянное место — меньше поиска | Меню всегда в одном месте, наставник — всегда в центре меню и справа на компьютере |
| Типографика и тональность поверхностей | Apple HIG | Иерархия держится на размере и весе, а не на рамках | Глубина — тоном поверхностей. Тень только у плавающих элементов |
| Тихий интерфейс, громкий контент | Things 3 | Задача на виду, интерфейс не мешает | Чертёж — самый крупный объект экрана разбора. Управление вокруг него приглушено |

### 1.2. Наука → правило в интерфейсе

| Закон или исследование | Правило «Связи» | Где проверить |
|---|---|---|
| Закон Хика | На экране 1 главное действие и не больше 4–5 вариантов в группе | 4 стартера, 5 пунктов меню, 4 шага пути к сдаче |
| Закон Фиттса | Главная кнопка — 52 px высотой и во всю ширину. Внизу, в зоне большого пальца | «Продолжить с шага 5», «Дальше» в разборе |
| Когнитивная нагрузка (Sweller) | Шаг = одна идея + одна новая линия. Посторонние построения тонкие, текущее — Сурик | Разбор: прошлые посредники серые, текущие — Сурик |
| Гештальт: близость и общая область | Группы — карточки с отступом 12–16 px. Внутри — 4–8 px | Карточка «Сейчас»: срок, шаг и кнопка в одной области |
| Гештальт: сходство | Сурик всегда значит одно: «это сейчас / сюда» | Кнопка, линия построения, прогресс |
| Закон Якоба | Нижнее меню, мини-плеер, шторка, омнибокс — уже знакомы по YouTube, Spotify, Chrome | Вся навигация |
| Порог Доэрти (< 400 мс) | Любой отклик ≤ 100 мс. Загрузка дольше 400 мс — скелетон или статус | Состояние «думает», скелетон разбора |
| Пик — конец (Kahneman) | Пик — момент «понял» на чертеже. Конец — звёзды и «Повторим через 3 дня» | Конец теста, конец разговора с наставником |
| Эффект Зейгарник | Незавершённое на виду, но без давления | Мини-панель, полоса в «Продолжить» |
| Модель привычки (Hooked), этичная | Триггер — твой реальный срок или повторение. Действие — 3 минуты. Награда — понимание, а не случайный приз. Вклад — твой прогресс | Система возвратов (раздел 8) |
| Проверка себя (Roediger, Karpicke) | После разбора — вспоминание, а не повтор просмотра | «Проверь себя», тест «где верно», «Защита» |
| Интервальное повторение (Cepeda) | 1 → 3 → 7 → 16 дней, сдвиг после ошибки на 1 день | Навыки, «План» |
| Эффект генерации | Сначала предскажи, потом смотри | Режим «Решаю сам» |
| Material Motion, Apple HIG | Движение объясняет, откуда и куда. Не больше одной хореографии за раз | Обложка карточки превращается в шапку страницы |
| WCAG 2.2 | Текст ≥ 4.5:1, границы и значки ≥ 3:1, цель ≥ 24 px (у нас 44 px), фокус виден, ничего не держится только на цвете | `contrast.js`, раздел 3.2 |

### 1.3. Антипаттерны — чего не делаем

- **Тёмные паттерны:** подтверждение стыдом («Нет, я не хочу учиться»), фальшивые таймеры, серия, которая сгорает за один пропуск,
  скрытая кнопка «отписаться», регистрация до пользы, «осталось 2 места».
- **Ответ под замком.** Решение не прячем за тестом или входом: путь «метод → попробуй → разбор → проверь» лёгкий, но не обязательный.
- **Модалки поверх модалок.** Одна шторка за раз. Никаких всплывающих окон при входе, «оцените нас», «включите уведомления» на первом экране.
- **Навязчивые уведомления.** Не больше одного напоминания в день и не больше 3 в неделю. Только реальный срок или повторение. Тихие часы — с 22:00 до 9:00.
- **Стикеры, эмодзи, маскоты, конфетти, 3D-иконки.** Вместо них — геометрия предмета.
- **Случайные цвета.** У каждого цвета одна роль. Нет градиентов «для красоты», нет разноцветных плиток разделов.
- **Тени ради глубины.** Глубина — тоном поверхностей. Тень только у того, что парит: мини-панель, шторка, выпадающий список.
- **Кнопки с «бортиком», CAPS, жирный на всём.** Вес 600 — только заголовки и подписи кнопок.
- **Канцелярит и пассив:** «Осуществите переход», «Данный раздел», «Произошла ошибка». Пишем глаголом и на «ты».
- **Анимация без смысла:** параллакс, бесконечные пульсации, автокарусели. Движение только объясняет переход или состояние.
- **Геймификация вместо учёбы:** очки за просмотр, лидерборды по времени. Статус дают только за то, что решил сам.

## 2. Принципы «Связи»

1. **Чертёж — главный герой.** Если на экране есть чертёж, он самый крупный, а интерфейс вокруг него тихий (Things, Apple HIG; нагрузка Sweller).
2. **Одно «сейчас».** На экране одно главное действие цвета Сурик. Всё остальное — тоном (закон Хика, pop-out Treisman).
3. **Учиться — самый короткий путь.** Готовый разбор доступен сразу, но «попробуй сам» стоит на одно касание ближе (эффект генерации, Brilliant).
4. **Наставник рядом, а не над тобой.** Одно касание с любого экрана, и он уже знает, где ты: ДЗ, вариант, шаг (Cursor, Claude Projects).
5. **Движение объясняет.** Каждая анимация показывает, откуда что взялось и куда делось. Фирменный жест — линия дочерчивается (Material Motion).
6. **Возвращаем пользой, а не страхом.** Поводы вернуться — твой срок и твоё повторение. Пропуск ничего не обнуляет (Hooked в этичных рамках).
7. **Быстро на слабом телефоне.** Первая отрисовка до 2 с, отклик до 100 мс, всё на CSS и Canvas (порог Доэрти; 80 % заходят с телефона).

## 3. Визуальный язык и токены

### 3.1. Палитра

Основа — нейтральный **графит** с лёгким холодным сдвигом (оттенок 220°, как грифель), а не чистый серый. Фирменный цвет один —
**Сурик**: красно-оранжевый пигмент, которым исторически размечали и грунтовали металл, и «красный карандаш» правки на чертеже.
Синий и красный старого сайта не используются. Сурик занимает свободное место среди образовательных брендов: у Duolingo и Brilliant
зелёный, у Khan Academy бирюзовый, у Notion и Linear сине-фиолетовый. На заливке Сурика пишем **тёмным** текстом, а не белым:
так контраст 5,3–6,8 : 1 в обеих темах, и кнопка читается как инструмент, а не как предупреждение.

- **Сурик — одна вещь на экране.** Если на экране две оранжевые кнопки, одна из них должна стать вторичной.
- **Смысл никогда только цветом.** «Верно» — значок ✓ и слово, «ошибка» — ✕ и слово, срок — часы и дата.
- **Ошибка отличается от Сурика** по оттенку (345° против 20°), по светлоте и по форме: ошибка всегда в кольце с номером.
- **Срок** жёлтый с тёмным текстом, только когда до сдачи ≤ 3 дней. Раньше — нейтральная метка, позже — ошибка «Срок прошёл».

**Выбор — «Огибающая».** Она одна и узнаётся в любом размере, у неё шесть различимых состояний без лица, и она построена тем
же способом, каким студент строит чертёж: касательными и проекцией. Из варианта А берём **линию связи**. Когда наставник показывает
что-то на чертеже, от точки тянется пунктир Сурика, и место подсвечивается (в прототипе — диалог «Застрял на шаге»).

### 5.2. Геометрия

Окружность радиуса R = 0.28 размера холста, N касательных (24 в главной, 12 в меню и шапке), равномерно по углу плюс фаза
вращения. Каждая касательная — отрезок длиной ±L·R от точки касания. Плоскость окружности повёрнута на наклон α вокруг
горизонтальной оси и рыскание β (дрейф ±0.2 рад за 33 с), проекция ортогональная. Передние касательные — сплошные, линия 1.5 px.
Задние — штрих 3/3, прозрачность 0.22–0.45 (на 44 px и меньше — без штриха). Цвет — смесь `ink-1` и Сурика в пропорции «тепла» состояния.

| **Ошибка** | нет сети, не распознал фото, неверный ответ в тесте | 0.3 рад | почти стоп, 0.06 | 0.9 | `--err` | верхний сектор касательных распадается (разрыв), сдвиг ±6 px с частотой 7 Гц, затухает за 250 мс | через 1.4 с — в ожидание |
| **Успех** | верный ответ, шаг понят, ошибка на листе исправлена | 0.04 рад — почти идеальный круг | 0.35 рад/с | 0.22 — касательные «собираются» в чистую окружность | Сурик | в центре появляется точка, пружина bouncy (k 520, c 26, отскок 11 %), вибрация 8–40–8 мс на Android | через 1.7 с — в ожидание |
| **Касание** | палец на «Огибающей» | — | фаза +0.4 рад | — | — | сжатие: пружина k 520, c 26 по радиусу, вибрация 6 мс | — |

Производительность: один общий `requestAnimationFrame` на все экземпляры. Отрисовка останавливается, когда холст не в документе или
вкладка скрыта. Плотность пикселей не больше 2. Режим «меньше движения»: нет вращения, дыхания, колебаний и тряски. Состояния
показываются формой и цветом за один кадр (раскрытие касательных, разрыв, точка в центре), кадр рисуется только при смене состояния.

Размеры: 168 px (главная), 200 px (главная на компьютере), 128 px (пустой разговор), 44 px (меню), 36 px (шапка разговора, кнопка
«Спросить»), 28 px (аватар ответа — статичный SVG-глиф из 10 касательных).

### 5.4. Поведение

- **Где живёт.** Главная — в центре, с полем и стартерами. Меню — центральная кнопка, одно касание с любого экрана. Разбор — кнопка
  «Спросить» в нижней панели: открывает разговор о текущем шаге. Компьютер — пристыкован справа на экранах предмета и задания.
- **Что знает.** Контекст (чип в шапке): предмет, ДЗ, вариант, шаг, режим «смотрю / решаю», ближайший срок, слабые навыки, последний
  разговор. Чип можно сменить или убрать касанием.
- **Как отвечает.** Коротко: 2–4 предложения, затем действие на чертеже или 2–3 кнопки ответа. Сначала наводящий вопрос, но рядом
  всегда «Не знаю — покажи» — один шаг до ответа, без допросов. Не выдумывает: геометрию берёт из решателя сайта (`DZR.solve`),
  методику — из `method.types`. Если не уверен: «Не уверен. Вот что точно видно на твоём чертеже: …».
- **Рисует на чертеже.** Ответ может содержать блок «чертёж»: тот же вычисленный эпюр варианта, где наставник дочерчивает
  посредник, линию связи и точку (Сурик, жест «линия дочерчивается»), а точка пульсирует дважды.
- **Ошибки.** Нет сети — «Огибающая» в ошибке, текст «Нет связи. Вопрос сохранён — отправлю сам, когда появится сеть», кнопка
  «Повторить». Фото не читается — «Лист плохо видно: сними сверху, при свете, чтобы влезла рамка» и пример кадра.
  Длинное ожидание (> 8 с) — «Думаю дольше обычного. Можно пока открыть разбор шага 5» со ссылкой.
- **Память.** История разговоров — в профиле, по ДЗ. Без входа хранится на устройстве.

### 5.5. Стартеры: как собираются

По порядку, берём первые 4: (1) начатый шаг — «Застрял на шаге N»; (2) срок ≤ 3 дней и лист не проверен — «Проверь лист по фото»;
(3) следующее ДЗ, которое ещё не начато — «С чего начать ДЗ №N»; (4) сданное ДЗ без защиты — «Подготовь к защите ДЗ №N»;
(5) навык на повторение — «Повтори видимость — 3 минуты»; (6) новичок — «Как устроен Начерт», «Найди мой вариант».

### 5.6. Микрокопия наставника

| Ситуация | Текст |
|---|---|
| Пустой разговор | «Я знаю твой вариант и сроки» · «Объясню шаг на твоём чертеже, найду ошибку на фото листа, подготовлю к защите.» |
| Плейсхолдер | главная — «Задача, вариант или вопрос» · разговор — «Спроси или пришли фото» |
| Думает | «Смотрю твой шаг 5» → «Сверяю с решением варианта 13» · «Выравниваю лист по эталону» → «Сверяю 14 точек» → «Проверяю видимость» |
| Долго | «Думаю дольше обычного. Пока можно открыть разбор шага 5.» |
| Нет сети | «Нет связи. Вопрос сохранён — отправлю, когда появится сеть.» |
| Не понял | «Не понял, о каком шаге речь. Это ДЗ №4, вариант 13?» + кнопки «Да» / «Другое ДЗ» |

### 5.7. Пять диалогов (все пять — в прототипе)

**1. «Застрял на шаге»** (контекст: ДЗ №4, вариант 13, шаг 5)
> **Ты:** Застрял на шаге 5. Где брать промежуточные точки?
> **Наставник** *(думает: «Смотрю твой шаг 5 → Сверяю с решением варианта 13»)*: Ты уже нашёл точки 1–5 — значит, приём знаешь.
> Промежуточные ищутся так же. Вопрос к тебе: какая плоскость режет и конус, и цилиндр по простым линиям?
> `[Горизонтальная]` `[Фронтальная]` `[Не знаю — покажи]`
> **Ты:** Горизонтальная.
> **Наставник:** Да, горизонтальная. Конус она режет по окружности, цилиндр — по двум образующим. Провожу её через точку 6″:
> *[чертёж варианта 13: дочерчивается след плоскости Σ, окружность на П₁, образующая, линия связи; точки 6″ и 6′ пульсируют]*
> Где окружность пересекла образующую — там 6′. Возьми плоскость пониже и найди 7′ сам. `[Нашёл, сверим]` `[Покажи 7′]`
> *(на «Фронтальную»: «Огибающая» — ошибка. «Не совсем: фронтальная плоскость режет конус по гиперболе — её точно не построишь.
> Нужна такая, что даёт окружность.»)*
> **Наставник** *(успех)*: Точка 7′ — здесь. Если у тебя так же, шаг 5 готов. Повторим посредники через 3 дня, чтобы на РК это было
> на автомате. `[К шагу 6]` `[Напомнить через 3 дня]`

**2. «Проверь мой лист по фото»**
> **Ты:** *[фото листа]* Проверь мой лист
> **Наставник** *(«Выравниваю лист по эталону → Сверяю 14 точек → Проверяю видимость»; по фото бежит линия сканирования)*:
> *[фото с двумя кольцами ошибок и номерами]* Нашёл 2 ошибки. Остальное совпадает с эталоном варианта 13.
> **① Точка 3′ сдвинута.** Она на очерковой образующей конуса, значит на П₁ — ровно на горизонтальной оси. У тебя ниже на 4 мм.
> **② Участок 5–2 видимый.** Он на нижней половине цилиндра — сверху его не видно. Обведи штрихом.
> `[Исправить вместе]` `[Наложить эталон]` `[Проверить снова после правки]`
> *(«Наложить эталон» — поверх фото пунктиром Сурика ложится верная кривая и точка 3′)*

**3. «С чего начать ДЗ №5»**
> **Наставник:** ДЗ №5 — прямая и поверхность. В твоём варианте прямая пересекает сферу. Главный приём — плоскость через прямую,
> которая режет сферу по окружности.
> 1. Через прямую проведи проецирующую плоскость. 2. Найди окружность — сечение сферы этой плоскостью. 3. Повтори заменой плоскостей:
> окружность станет окружностью, а не эллипсом. 4. Точки входа и выхода — где прямая встретила окружность. Видимость — по конкурирующим точкам.
> На всё с оформлением — около 2 часов. Начни с метода: 3 минуты, и шаги станут понятны. `[Открыть метод]` `[Попробую сам]`

**4. «Подготовь к защите»**
> **Наставник:** Задам 5 вопросов по твоему листу — как на защите. Отвечай своими словами, можно голосом.
> **Вопрос 1 из 5.** Зачем во второй задаче две замены плоскостей, а не одна? `[Ответить]` `[Не знаю — подскажи]`
> **Ты:** Первая делает прямую уровня, вторая — проецирующей.
> **Наставник** *(успех)*: ✓ Верно. Для полного ответа добавь: после второй замены грань проецируется в прямую — так видна натуральная
> величина угла. Счёт 1 из 5. Следующий вопрос — про вращение вокруг горизонтали. `[Следующий вопрос]` `[Хватит, повторю завтра]`
> *(«Не знаю» → подсказка: «За одну замену прямая общего положения становится только прямой уровня. Что нужно, чтобы она выродилась в точку?»)*

**5. «Объясни теорему о прямом угле»**
> **Наставник:** **Прямой угол проецируется в натуральную величину, если одна его сторона параллельна плоскости проекций, а другая ей
> не перпендикулярна.** *[эпюр: горизонталь h и отрезок A; на П₂ угол не прямой, на П₁ — прямой, знак угла Сурика]*
> Как другу: положи угольник на стол, одной стороной вдоль края, а вторую приподними. Сверху угол всё равно прямой — пока первая сторона
> лежит ровно. Где пригодится: в ДЗ №1 высота ⟂ MN, в ДЗ №5 нормаль через горизонталь и фронталь.
> `[Проверь меня: 2 вопроса]` `[Открыть в теории]`

## 6. Карта сайта и навигация

### 6.1. Схема: 4 + 1 + мини-панель + одна строка

```
Нижнее меню (телефон) / рейка (компьютер):
  Главная · Предметы · ◉ Наставник · План · Я
Над меню: мини-панель «Сейчас делаешь» (последний начатый шаг)
На главной и в «Поиске»: омнибокс — поиск и вопрос в одной строке
```

Почему так: 5 пунктов — предел для нижнего меню (Material, HIG) и уже знакомая схема (YouTube: Главная · Shorts · ＋ · Подписки · Вы).
Наставник в центре — самая лёгкая цель для большого пальца (Фиттс) и смысловой центр сервиса. «План» отдельно, потому что сроки и
повторения — главный повод вернуться. Поиск — не пункт меню, а строка на главной: студент знает номер, а не раздел (`docs/IA.md`).

### 6.2. Дерево и число касаний с главной

```
Главная #/
├─ Омнибокс → задача N, ДЗ, вариант, тема, «спросить наставника»      1 (ввод + Enter)
├─ Стартеры → разговор с наставником                                   1
├─ «Сейчас» → разбор варианта на нужном шаге                           1
├─ «Продолжить» → начатое                                              1
├─ Предмет НГ / ИГ                                                     1
│   ├─ ДЗ → карточка задания                                           2
│   │     ├─ разбор варианта (Смотрю / Решаю)                          3
│   │     ├─ подготовка: карта уровней → уровень → тест               3–4
│   │     ├─ метод, ошибки, вопросы защиты (раскрываются на месте)     2
│   │     └─ лист: чистовик, черновик, нормоконтроль, проверка по фото 3
│   ├─ Тетрадь → задача N                                              3 (или 1 через омнибокс)
│   ├─ РК → билеты, пробный РК                                         3
│   ├─ Теория → тема                                                   3
│   └─ 3D-эпюр                                                         2
├─ Автор → шторка → «Как мы учим»                                      2
Наставник (меню)                                                       1
План: сегодня (повторения), сроки                                      1
Я: штамп, ритм, навыки, разговоры, настройки, вход                     1
```

Любая цель — не больше 3 касаний. Самое частое (задача по номеру, свой вариант, продолжить начатое) — 1 касание.

### 6.3. Адреса

Сохраняем текущие адреса, чтобы не сломать ссылки в чатах групп: `#/ng4/13` (разбор), `#/ng4/13/list`, `#/ig3/7`, `#/ng/tasks/47`,
`#/dz`. Новые: `#/agent`, `#/plan`, `#/me`, `#/search?q=`, `#/ng4/13?mode=self&step=5`. Прототип использует короткие `#home`,
`#variant` — это демонстрация, не схема.

### 6.4. «Где я, что здесь, что дальше» за 3 секунды

- **Где я:** шапка всегда в два уровня: заголовок экрана и под ним родитель («ДЗ №4 · вариант 13» / «Конус и цилиндр»). Плюс
  выбранный пункт меню.
- **Что здесь:** самый крупный объект экрана и есть суть: чертёж в разборе, «Что разберём?» на главной, «Где верно?» в тесте.
- **Что дальше:** одна кнопка Сурика внизу экрана: «Продолжить с шага 5», «Дальше», «К тесту «где верно»».

## 7. Экраны (телефон 390 px и компьютер 1280 px)

Общие состояния: **загрузка** — скелетон по форме будущего контента (`surface-2` с бегущим бликом 1.2 с; в режиме «меньше движения»
без блика), если ждать > 400 мс. **Ошибка** — на месте контента: что случилось и что сделать, кнопка «Повторить». Сайт работает
без сети на уже открытых разборах (service worker, `sw.js`). **Пустое** — объясняет, что здесь появится, и даёт одно действие.

### 7.1. Первый заход (онбординг ≤ 3 экранов, `#hello`)
- **Цель:** за 15 секунд показать главное и узнать вариант, чтобы дальше всё открывалось сразу «твоим».
- **Путь:** «Твой вариант — на твоём чертеже» → «Что сдаёшь?» (НГ / ИГ, можно оба) → «Какой у тебя вариант?» (сетка 1–30) → главная.
  «Пропустить» на каждом экране. Без входа и без разрешения на уведомления.
- **Иерархия:** «Огибающая» → заголовок → одна строка → точки шагов → главная кнопка.
- **Компьютер:** то же в карточке 480 px по центру.
- **Тексты:** «Начать», «Дальше», «Готово», «Пропустить». Тост: «Готово. Вариант 13 запомнили».

### 7.2. Главная (`#home`)
- **Цель:** с порога начать: спросить, найти или продолжить.
- **Путь:** открыл → поле или стартер (1 касание) / «Продолжить с шага 5» (1 касание).
- **Иерархия (сверху вниз):** шапка (логотип, поиск, тема) → «Огибающая» 168 px → «Что разберём?» → омнибокс → 4 стартера →
  **«Сейчас»** (срок, шаг, одна кнопка) → полка «Продолжить» → **Предметы** (две карточки рядом — расположение сохранено) → автор → подвал.
- **Компьютер:** рейка слева. Агент шире: «Огибающая» 200 px, поле 64 px, стартеры в ряд. Ниже две колонки: «Сейчас» и «Продолжить».
- **Пустое (новый человек):** «Сейчас» → «Выбери вариант — откроем твои разборы» (кнопка «Выбрать вариант»). Полки «Продолжить» нет.
  Стартеры — «Найди задачу по номеру», «Как устроен Начерт», «Проверь лист по фото».
- **Загрузка:** главная рисуется сразу из локальных данных, карточки — скелетоны не дольше 400 мс.
- **Ошибка:** нет сети — поле работает как поиск по открытым разборам, у наставника подпись «Наставник ответит, когда появится сеть».
- **Тексты:** «Что разберём?» · «Спроси про шаг, пришли фото листа или найди задачу по номеру.» · «Сейчас» · «Сдача через 2 дня» ·
  «Продолжить с шага 5» · «Продолжить» · «Предметы» · «Автор — Андрей Матханов».

### 7.3. Разговор с наставником (`#agent`)
- **Цель:** понять шаг, найти ошибку, подготовиться к защите.
- **Путь:** стартер или вопрос → «думает» со статусом → ответ потоком → действие на чертеже → 2–3 кнопки ответа.
- **Иерархия:** шапка (назад · «Огибающая» 36 · «Наставник» · чип контекста · новый разговор) → сообщения: твои справа на `surface-3`,
  ответы слева без пузыря (текст главнее рамки, как в Claude и ChatGPT) → поле внизу над клавиатурой.
- **Компьютер:** колонка 720 px по центру. На экранах предмета и задания — пристыкованная панель справа.
- **Пустое:** «Огибающая» 128 px, «Я знаю твой вариант и сроки», 5 сценариев списком.
- **Загрузка / ошибка:** раздел 5.6.
- **Тексты:** раздел 5.6.

### 7.4. Раздел предмета (`#subject-ng`)
- **Цель:** найти своё ДЗ, задачу тетради, РК или тему.
- **Путь:** Предметы → вкладка → карточка (2–3 касания).
- **Иерархия:** шапка → обложка-эпюр (общий элемент с карточкой на главной) → «Начертательная геометрия» + состав → вкладки ДЗ ·
  Тетрадь · РК · Теория · 3D-эпюр → список. ДЗ отсортированы по сроку: текущее с жёлтой меткой и полосой, сданные с ✓, будущие с
  «Метод и уровни открыты заранее».
- **Тетрадь:** сетка номеров 1–89, решённые — зелёная точка, следующая — кольцо Сурика. Подпись «Решено 16 из 89 · следующая — 47».
- **Компьютер:** ДЗ в две колонки, справа наставник «Видит: Начертательная геометрия».
- **Пустое:** «Здесь появятся твои ДЗ. Выбери вариант — и разборы откроются сразу твои».
- **Тексты:** «ДЗ №4», «Сдача в чт, 26 ноя», «Сдано 15 окт», «Вариант 13».

### 7.5. Карточка задания (`#task`)
- **Цель:** понять задание и выбрать путь: разобраться или сразу посмотреть решение.
- **Путь к сдаче (главное на экране):** **Метод → Попробуй сам → Разбор → Проверь себя**. Текущий шаг пути — кружок Сурика. Главная
  кнопка ведёт в текущий шаг: «Продолжить: шаг 5 из 7». Под ней — текстовая «Открыть готовый разбор». Решение доступно сразу,
  но лёгкий путь — учиться.
- **Иерархия:** шапка (ДЗ №4 · поделиться) → обложка → название → срок, вариант → путь → кнопка → «Как решать» (метод в трёх шагах
  открыт, типичные ошибки, вопросы на защите с кнопкой «Тренировать с наставником») → «Подготовка» (следующий уровень со звёздами)
  → «Лист» (чистовик, черновик, нормоконтроль, проверка по фото).
- **Компьютер:** обложка 21:9, справа наставник со стартерами «С чего начать ДЗ №4», «Проверь мой лист по фото», «Подготовь к защите».
- **Пустое:** вариант не выбран — вместо пути сетка вариантов «Выбери свой вариант — он запомнится для всех ДЗ».
- **Тексты:** «Путь к сдаче», «Продолжить: шаг 5 из 7», «Открыть готовый разбор», «Метод в трёх шагах», «Типичные ошибки · 3»,
  «Вопросы на защите · 6».

### 7.6. Разбор варианта (`#variant`)
- **Цель:** пройти построение по шагам и понять каждый.
- **Путь:** шаг → (Почему так? / Проверь себя) → «Дальше» → … → «К тесту «где верно»».
- **Иерархия:** шапка (ДЗ №4 · вариант 13 · переключатель **Смотрю / Решаю**) → **чертёж** (самый крупный, сетка листа, текущее
  построение Суриком и дочерчивается, прошлые — тонкие; номер шага, кнопка 3D) → главы на шкале → карточка шага (overline, заголовок,
  текст, «Почему так?», «Проверь себя») → нижняя панель: ← · «Спросить» (с «Огибающей») · **Дальше**.
- **Режим «Решаю»:** чертёж показывает предыдущий шаг, в карточке — «Сначала попробуй сам: где окажутся 3′ и 4′? Подумай 30 секунд»,
  кнопки «Намёк» и «Показать шаг». «Дальше» сначала открывает шаг, а уже потом листает.
- **Компьютер:** чертёж слева (≈ 60 % ширины, прилипает при прокрутке), шаги справа. Наставник по кнопке «Спросить». Стрелки ← →
  листают шаги, цифры 1–7 переключают главы.
- **Загрузка:** скелетон чертежа и карточки (380 мс в прототипе).
- **Ошибка:** «Чертёж не построился. Обнови страницу — или открой готовый лист в PDF» (решатель упал — не оставляем пустоту).
- **Тексты:** «Шаг 5 из 7», «Промежуточные точки 6 и 7», «Почему так?», «Проверь себя», «Сначала попробуй сам», «Намёк», «Показать шаг», «Дальше».

### 7.7. Уровень подготовки (`#levels`)
- **Цель:** подготовиться к ДЗ маленькими шагами. Уровень = условие → разбор → тест → звёзды.
- **Иерархия:** шапка «Подготовка к ДЗ №4 · 8 из 18 звёзд» → одна строка правил → путь уровней на пунктирной линии связи: пройденные
  (графит, звёзды), текущий (Сурик с ореолом, «Следующий · 3 мин»), закрытые («Откроется после уровня 3») → «Начать уровень 3».
- **Компьютер:** путь слева, превью текущего уровня справа.
- **Тексты:** «Три звезды — когда тест с первой попытки».

### 7.8. Тест «где верно» (`#test`)
- **Цель:** проверить себя одним касанием.
- **Иерархия:** шапка (уровень, «Вопрос 1 из 3», закрыть) → сегменты → «Где верно?» → условие → два чертежа → итог.
- **Пик и конец:** звёзды выскакивают по одной, и сразу «Повторим через 3 дня». Ошибка — без красного экрана: «Не в этот раз ·
  Смотри на нижнюю половину» и объяснение.
- **Компьютер:** чертежи по 420 px, клавиши A / Б (или ← →).

### 7.9. Профиль и прогресс (`#me`)
- **Цель:** увидеть свой рост и управлять напоминаниями.
- **Иерархия:** **Штамп** — карточка в виде основной надписи листа: статус («Черновик»), шкала Эскиз → Эталон, что нужно до следующего,
  ячейки «Студент · Группа · Решено сам · Звёзды» → «Сохрани прогресс» + «Войти через Яндекс ID» (без входа скрыто для вошедших) →
  **Ритм** (неделя, 2 из 3) → **Навыки** (полоса и дата повторения) → **Разговоры с наставником** → **Настройки** (меньше движения,
  напоминания, первый заход).
- **Компьютер:** две колонки: штамп и ритм слева, навыки и разговоры справа.
- **Пустое:** «Штамп появится после первого шага, который решишь сам».
- **Тексты:** «Статус», «До «Чистовика» — 3 уровня на три звезды», «Цель — 3 учебных дня в неделю. Пропуск ничего не обнуляет».

### 7.10. Поиск (`#search`)
- **Цель:** найти по номеру или словами.
- **Иерархия:** поле в фокусе → пусто: «Недавнее» и подсказка «Пиши как удобно: «47», «дз 4 вариант 13», «не понимаю замену
  плоскостей»» → результаты группами: прямое попадание, ДЗ и варианты, задачи, теория, «Спросить наставника».
- **Ничего не нашлось:** «Ничего не нашлось. Спроси наставника — он поищет по смыслу.»

### 7.11. План (`#plan`) — повод вернуться
«Сегодня · 12 минут»: повторение (3 мин) и продолжение шага → «Сроки» по датам (жёлтое — ≤ 3 дней) → «Сроки взяты из расписания
группы СМ5-11 · Сменить группу».

## 8. Система возвратов

**Правила этики.** Поводы — только твои реальные сроки, твои повторения и новые материалы по твоему предмету. Не больше одного
напоминания в день и трёх в неделю. Тихие часы — с 22:00 до 9:00. Каждое уведомление отключается одним касанием, прямо в нём. Нет
серий, которые сгорают, и нет «ты нас забыл». Каналы: веб-push (только после того, как человек сам включил «Напоминать о сроках»),
Telegram-бот (по желанию) и плашка «Сейчас» на главной — она работает всегда, без разрешений.

| Событие | Повод | Частота и ограничения | Что видит человек |
|---|---|---|---|
| До срока ДЗ 3 дня, разбор не начат | Срок | 1 раз | «ДЗ №4 сдавать в четверг. Начни с метода — 3 минуты» → карточка задания |
| До срока 1 день, лист не проверен | Срок | 1 раз, в 19:00 | «Завтра сдача ДЗ №4. Проверь лист по фото — найду ошибки до преподавателя» → камера |
| Начатый шаг брошен > 2 дней | Незавершённое (Зейгарник) | не чаще раза в 4 дня | «Ты остановился на шаге 5 из 7. Осталось минут 15» → разбор |
| Навык подошёл к повторению (1-3-7-16 дней) | Интервальное повторение | не больше 1 в день, собираются в «Сегодня» | «Повтори видимость — 3 минуты, и она закрепится» → тест |
| Ошибка в тесте | Повторение | на следующий день | «Вчера видимость не далась. Вот похожий чертёж» |
| Новый уровень или разбор по твоему ДЗ | Новое | не чаще раза в неделю | «Открыт уровень «Сферы-посредники» для ДЗ №4» |
| До РК 7 дней | Срок | 1 раз | «РК-2 через неделю. Пробный — 25 минут, покажет, что повторить» |
| Неделя ритма выполнена | Награда (итог, а не случайная) | 1 в неделю, в воскресенье | «3 учебных дня на этой неделе. Чистовик ближе на 1 уровень» |
| Получен новый статус | Принадлежность | по событию | Штамп обновляется, кнопка «Поделиться штампом» (картинка 1080 × 1350) |
| Защита пройдена 5/5 | Пик | по событию | «Готов к защите ДЗ №3. Удачи завтра» |

**Культура аккаунта.**
- **Статус** растёт только за то, что решено самостоятельно: Эскиз (первый шаг сам) → Черновик (3 уровня на 3 звезды) → Чистовик
  (одно ДЗ: все уровни + проверка листа + защита 4/5) → Эталон (все ДЗ семестра так же). Просмотры и время не считаются.
- **Штамп** — твоя основная надпись: имя, группа, статус, «решено сам», звёзды. Её можно показать, как карту Amex: знак того, что
  умеешь, а не того, сколько сидел.
- **Ритм** — 3 учебных дня в неделю вместо ежедневной серии. Пропуск не сбрасывает счёт.
- **История разговоров** — по ДЗ: к ней возвращаются перед защитой.
- **Вход** — одна кнопка (Яндекс ID, VK ID или Telegram), только чтобы перенести прогресс на другое устройство. Без входа всё работает,
  прогресс хранится на телефоне.

## 10. Прототип

`docs/design-system/prototype.html` — один файл, без внешних зависимостей (шрифты из `fonts/`). Что можно сделать:

- главная → наставник → предмет → задание → разбор → тест — всё нажимается, обложки перелетают в шапки (Chrome и Safari 18+);
- живой наставник: дышит, наклоняется к полю, когда печатаешь, раскрывается и «переворачивается», пока думает, распадается при ошибке,
  собирается в окружность с точкой при успехе, сжимается от касания;
- **функция-прорыв №1 в действии:** «Застрял на шаге 5» → наставник дочерчивает посредник прямо на чертеже варианта 13;
- **функция-прорыв №2 в действии:** «Проверь лист по фото» → сканирование, два кольца ошибок поверх фото, «Наложить эталон»;
- **функция-прорыв №3:** «Подготовь к защите» — вопрос по листу, ответ, разбор ответа, счёт;
- разбор варианта: настоящий вычисленный чертёж (конус ∩ цилиндр: опорные точки, посредники, кривая, видимость), 7 глав,
  режимы «Смотрю / Решаю»;
- светлая и тёмная темы, «меньше движения», 360 / 390 / 1280 px.

**Вес.** CSS 44 КБ, JS 96 КБ без сжатия (10 + 30 КБ в gzip), весь файл — 41 КБ в gzip. Сама оболочка (CSS, «Огибающая», обложки,
навигация, шторка, тост, омнибокс, иконки) — около 75 КБ без сжатия и 22 КБ в gzip. Остальное — демо-данные, тексты диалогов
и чертёж ДЗ №4, которые на сайте уже есть в решателях. Бюджет 120 КБ соблюдён.

**Прототип не показывает:** настоящий ИИ (диалоги заготовлены), камеру (фото — заготовка), вход, 3D. На сайте наставник —
существующий `server/lib/tutor`, проверка по фото — существующие «глаза».

| 6 | Нужно сдать через 2 часа | Решебник, «скинь фотку», платный репетитор ночью | Скорость без понимания, на РК — провал |

| 9 | Стыдно спросить «глупый» вопрос | Молчат на семинаре | Пробел копится до РК |
| 10 | Оформление по ГОСТ: шрифт, рамка, линии | Сдают — возвращают — переделывают | Каждый круг — неделя |

### 12.2. Идеи и оценка (1–5)

### 12.3. Три функции-прорыва

#### Прорыв 1. «Наставник рисует на твоём чертеже»

- **Сценарий.** Студент на шаге 5 разбора нажимает «Спросить» (или пишет на главной «застрял на шаге 5»). Наставник уже знает ДЗ,
  вариант и шаг. Задаёт один наводящий вопрос с тремя кнопками. На ответ — дочерчивает на эпюре варианта 13 плоскость-посредник,
  окружность на П₁ и линию связи. Точка 6′ пульсирует. «Найди 7′ сам» → «Нашёл, сверим» → точка 7′ появляется, «Огибающая»
  собирается в окружность. Шаг засчитан, навык «посредники» уходит в повторение через 3 дня.
- **Почему переворачивает.** Сегодня объяснение (лекция, решебник, бот) живёт отдельно от чертежа и не про твой вариант. Здесь
  объяснение и есть чертёж, и он твой до миллиметра, потому что геометрия вычисляется кодом. ChatGPT может это сказать словами,
  но не может нарисовать точно. У решебника нет разговора.
- **Где встроено.** Главная — стартер «Застрял на шаге 5». Разбор — кнопка «Спросить» в нижней панели. Компьютер — панель справа,
  линия связи тянется от наставника к точке на чертеже слева.
- **Хайп и возврат.** «Поделиться шагом»: ссылка открывает другу чертёж на этом шаге с той же линией («смотри, как он мне показал»).
  Каждый такой разговор — в истории по ДЗ. Навык — в повторение.
- **Что нужно для запуска.** Наставник уже листает шаги и подсвечивает точки (`docs/TUTOR.md`). Нужен инструмент `draw` — список
  элементов из решателя (посредник, линия связи, точка) с ключами шага, и отрисовка их классом `draw` в `DRAW`.
- **Минимальная версия за неделю.** Только ДЗ №4, только «Почему здесь горизонтальная плоскость?» и «Покажи точку N», без
  свободного текста. Кнопка «Спросить» на шагах 4–6. **Метрика:** доля студентов на шагах 4–6, нажавших «Спросить», ≥ 15 %,
  и доля дошедших до конца разбора среди спросивших выше, чем среди не спросивших.

#### Прорыв 2. «Рентген листа»

- **Сценарий.** Вечер перед сдачей. Камера на главной (или стартер «Проверь лист по фото») → снимок → «Выравниваю лист по эталону →
  Сверяю 14 точек → Проверяю видимость» (линия сканирования по фото) → фото с кольцами ①② и короткими объяснениями.
  «Наложить эталон» — верная кривая пунктиром Сурика прямо поверх твоего листа. «Исправить вместе» — переход в прорыв 1 на нужном
  шаге. «Проверить снова после правки» — напоминание.
- **Почему переворачивает.** Сегодня обратная связь приходит через неделю и одним словом карандашом. Здесь — за 20 секунд, на твоём
  листе, с объяснением и путём исправления. Эталон точный для каждого варианта, потому что вычислен.
- **Где встроено.** Кнопка камеры в омнибоксе на главной и в разговоре. «Лист → Проверить по фото» в карточке задания.
  Напоминание за день до срока.
- **Хайп и возврат.** Картинка «до / после» с кольцами — то, что пересылают в чат группы («кинь в Начерт, он покажет, где косяк»).
  Каждая найденная ошибка — навык в повторение. Статус «Чистовик» требует проверенного листа.
- **Что нужно для запуска.** Проверка по фото уже есть (`eyes`, черновик листа как эталон). Нужны: координаты ошибки в системе
  листа (опорные точки рамки → гомография), вывод колец поверх фото, связка ошибки с шагом разбора.
- **Минимальная версия за неделю.** ДЗ №4, 3 типа ошибок: точка не на очерке, видимость, кривая ломаной. Без наложения эталона.
  **Метрика:** ≥ 30 % проверок в последние 48 часов до срока заканчиваются повторной проверкой после правки; доля «ошибка найдена
  верно» по ручной проверке 50 фото ≥ 85 %.

#### Прорыв 3. «Защита»

- **Сценарий.** После сдачи (или из карточки задания: «Вопросы на защите → Тренировать») наставник задаёт 5 вопросов **по твоему
  листу**, показывая на нём место («почему 3′ на оси?»). Ответ голосом или текстом. Разбор ответа: что сказано верно, чего не хватает,
  как звучит полный ответ. Итог 4/5, слабые вопросы — завтра.
- **Почему переворачивает.** Защиты боятся сильнее всего, а готовиться к ней не с кем: шпаргалки из чата не про твой лист. Это первый
  тренажёр, где экзаменатор видит твой чертёж.
- **Где встроено.** Стартер «Подготовь к защите ДЗ №3» после сдачи. Вопросы на защите в карточке задания. Уровень 6 в подготовке.
- **Хайп и возврат.** «Готов к защите: 5/5» — повод для сторис и часть статуса «Чистовик». Вечер перед защитой — естественный возврат.
- **Что нужно для запуска.** Вопросы защиты уже есть в методике (`method.types[код].защита`). Нужны: проверка ответа моделью по
  эталонным тезисам и распознавание речи (Web Speech API, где он есть, иначе текст).
- **Минимальная версия за неделю.** ДЗ №3, 5 вопросов текстом, кнопки «Ответить» и «Не знаю — подскажи». **Метрика:** ≥ 40 %
  начавших доходят до 5-го вопроса, ≥ 20 % возвращаются ко второй попытке.

### 12.5. Проверка себя

| Где может не сработать | Что скажет скептик | Исправление |
|---|---|---|
| Студенту нужен только ответ за час до сдачи, а мы задаём вопросы | «Я не просил урок» | Решение доступно с первого касания («Открыть готовый разбор»). У наставника всегда есть «Не знаю — покажи». Режим «2 часа до сдачи» — короткий план и проверка листа. Учим тем, что даём проверить свой лист, а не тем, что прячем ответ |
| Преподаватель: «Это ГДЗ, они перерисуют» | «Сдадут чужое — не своё» | Прорывы 2 и 3 работают только с **твоим** листом и **твоими** ответами. Статус растёт только за решённое сам. Чистовик для печати остаётся, но стоит в «Листе» после пути к сдаче. Готовы дать кафедре режим «вопросы защиты» для семинара |
| Рентген ошибается на плохом фото | «Наврал — я исправил правильное» | Показываем уверенность: при плохом кадре — «Не уверен, переснимай сверху». Кольцо ставим, только если совпадение с эталоном выше порога. Всегда кнопка «Здесь всё верно» — сигнал для улучшения |
| Наставник галлюцинирует в геометрии | «ИИ насочинял» | Геометрию берёт только из решателя, а модель лишь выбирает, что показать и как объяснить. Тесты `tests/tutor.js` и замеры `tools/tutor-eval.js` — на каждом релизе |
| «Огибающая» и анимации тормозят на слабом Android | «Лагает» | Один `requestAnimationFrame`, остановка вне экрана, ≤ 0.3 мс на кадр. При «меньше движения» — статика. Бюджет проверяем в Lighthouse на каждом этапе |
| Уведомления раздражают | «Отписался» | Максимум 1 в день и 3 в неделю, только по реальным срокам. Каждое отключается в одно касание |
| Конкуренты скопируют интерфейс | «Сделаем так же» | Интерфейс скопировать можно, а вычисленные чертежи 30 вариантов × 13 ДЗ, эталоны для фото и методику — нет. Защищает связка «точная геометрия + наставник + лист» |

## 13. Две итерации: что изменилось после критики

Черновик раскритиковали трое: **студент за час до сдачи**, **отличник, который хочет понять**, и **преподаватель, который опасается ГДЗ**.

- **Студент:** «Наставник в центре — а мне нужен разбор!» → Карточка «Сейчас» с одной кнопкой «Продолжить с шага 5» стоит сразу под
  полем. Омнибокс открывает вариант по номеру без разговора. В карточке задания под главной кнопкой — «Открыть готовый разбор».
- **Студент:** «Наставник допрашивает» → В каждом наводящем вопросе есть кнопка «Не знаю — покажи», ответ максимум через одно касание.
- **Отличник:** «Смотреть разбор — не значит понять» → Добавлен режим «Решаю сам»: новая линия скрыта, сначала предсказание, потом
  «Показать шаг». Рядом с каждым шагом «Почему так?» и «Проверь себя».
- **Отличник:** «Звёзды ничего не значат» → Звёзды даются только с первой попытки. Статус растёт только за решённое сам. После ошибки
  тот же навык возвращается завтра на другом чертеже.
- **Преподаватель:** «Красивый решебник» → Прорывы 2 и 3 строятся на листе студента, а не на нашем. «Чистовик для печати» перенесён
  из главного действия в блок «Лист» после пути к сдаче. Добавлены вопросы на защите в каждое задание.
- **Все трое:** ежедневная серия заменена недельным ритмом без сброса. Конфетти и маскот убраны: успех — это «Огибающая», собранная в
  окружность, и три звезды.
- **Доступность:** граница поля ввода не дотягивала до 3:1 (1.6:1) → отдельный токен `--field` (3.3–3.6:1). Сурик на светлом фоне
  был 2.8:1 → затемнён до `#EB5310` (3.3:1), подпись на нём тёмная (5.3:1).
- **Наставник:** первая версия «Огибающей» с короткими касательными выглядела как пушистое кольцо → касательные длиннее, их меньше
  (24), задние — штрихом. Теперь видно, что это построение.
- **Вёрстка:** фиксированные панели (поле разговора, панель разбора) вынесены из анимируемого экрана — иначе на время анимации они
  «уезжали» вместе с ним. Разбор на компьютере — без пристыкованного наставника, чтобы чертёж занимал 60 % ширины.
