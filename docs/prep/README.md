# Подготовка к ДЗ и РК — прототипы

Черновики формата «методички» (ноябрь 2026). На сайт не подключены.

| Файл | Что это |
|---|---|
| `program.html` | Программа курса НГ: 48 тем, у каждой одна новая идея; привязка к 89 задачам тетради, вопросам РК1, типам РК2 и ДЗ №1–5; полнота и порядок проверяются на самой странице |
| `topic-posrednik.html` | Тема-образец к ДЗ №4 «Посредник — плоскость уровня»: 3D и эпюр, разбор по шагам, проверка дуэлью двух карточек (рейтинг Эло, правило 85 %, BKT с учётом угадывания) |

Файлы — тело страницы для просмотрщика Artifact (без `<!doctype>`). В `topic-posrednik.html` вместо `__OSIFONT__`
подставляется `fonts/osifont-italic.woff2` в base64.
