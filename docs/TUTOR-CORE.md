# Ядро ИИ-тренера

Второй шаг плана: ядро, которое не ошибается, и тренер, который говорит только то, что ядро разрешило.
Основа — `docs/AI-TUTOR-RESEARCH.md` (ветка `claude/kind-noether-uy0fck`), §3–4.

## Слои

| Слой | Файл | Что делает |
|---|---|---|
| Решатели и геометрические ядра | `dz/ng/*/solver.js`, `core/certify.js`, `core/conj.js`, 3D-ядро `IG3` | вычисляют каждый шаг каждого варианта; начерт — с сертификатом условия, сопряжения — с проверкой определения касания |
| Происхождение линий инжи | `dz/ig/*/lines/`, `core/ig-explain.js`, `kb/ig-dz.json` | каждая линия каждого вида: элемент, поверхности, откуда координаты |
| Пошаговые данные тренера | `tools/tutor-make.js` → `kb/tutor/<дз>.json` | на каждый шаг: цель, ступени 1–5, словарь меток, секреты (найденные точки, вычисленные числа), темы программы |
| Тренер | `core/tutor.js` | автомат лестницы (§4.1), контекст ступени для модели, линтер ответа, шаблон без модели, соседний вариант для Р4 |
| Граф знаний | `tools/kb-graph.js` → `kb/graph.json` | темы, ловушки, варианты, элементы, шаги тренера; id — хеш содержимого и опор, факты пересчитываются ядром (`--verify`) |

## Ступени

| Ступень | Тренер | Источник |
|---|---|---|
| Р0 | вопрос о цели шага | `goal` |
| Р1 | стратегия, без объекта | «Намёк» (секреты замаскированы) |
| Р2 | объект и правило | «Почему так?» |
| Р3 | где действовать, без результата | «Шаг», первые предложения, секреты замаскированы |
| Р4 | этот же шаг полностью на соседнем варианте того же типа | `neighborOf` |

Свой вариант ученика тренер не решает ни на одной ступени: найденные точки и числа шага модель не получает вообще, их знает
только линтер.

## Линтер (`lint(text, ctx)`)

Перед проверкой текст приводится к виду чертежа (`canonText`): апострофы, кавычки, LaTeX `^{\prime}`, «K-штрих», «два штриха»,
пробел перед штрихом, кириллические двойники латинских букв в метках, полноширинные цифры — всё это обход, и всё ловится.
Отказ, если в ответе: больше 320 символов; больше одного вопроса; «понятно?»; похвала личности; метка, которой нет на
чертеже и в открытых ступенях; найденная точка шага; вычисленное число шага; число не из условия, цели или открытых ступеней;
числительное словами от «четырёх» (числа подставляет интерфейс из ядра); вопрос «да/нет» о положении искомого.
При отказе — одна перегенерация, потом `fallback` (шаблон ступени, всегда проходит).

## Лестница (`ladder.step`)

Ступень растёт только после новой попытки (действие или содержательная реплика) или паузы (60 с до первой подсказки, 45 с
дальше, паузой — не выше Р3); просьба без новой попытки — «попробуй сначала»; каждая ошибка из библиотеки сначала показывается
(`feedback_incorrect`) без подъёма; Р4 — после двух ошибок на Р3 или просьбы после попытки; верный шаг после Р2+ — просьба
объяснить своими словами (`ask_self_explain`); перед РК лестница сжата: Р0 → Р2 → Р4 (`init({rk:true})`); три шага подряд
с Р4 — `review()` отдаёт темы, к которым стоит вернуться.

## Проверка утверждений ученика

- Начерт — `checkClaim(variant, stepId, claim)` по координатам всех точек варианта: точка на прямой, линия связи, ∥, ⟂, ∥ оси x.
  Утверждение о точке, которую шаг ещё не открыл, — `hidden` (да/нет о положении искомого не даём). `parseClaim` — разбор фразы.
- Инжа — `checkIG(explain, claim)` по базе «каждая линия»: откуда координата, дан ли элемент на виде, есть ли невидимые и
  кривые линии (результат — подтверждаем с Р3), попадает ли в разрез, штрихуется ли. `parseIGClaim` — разбор фразы.

## Ключевой ракурс

У каждого шага `look: {cam, t}` — куда тренер ведёт 3D-камеру (вдоль вспомогательной плоскости, перпендикулярно новой
плоскости проекций, вдоль оси вращения…); у шагов инжи — ракурс темы или вид, на котором элемент достраивают.

## Цифры (tests/tutor.js)

- 2485 шагов: начерт 1769 (ДЗ 1–5, по 30 вариантов), инжа 716 (ДЗ 2–6, 147 вариантов). У каждого — цель, ступени 1–3,
  тема программы, ключевой ракурс, соседний вариант для Р4.
- Шаблон без модели проходит линтер на каждой ступени каждого шага.
- Подсаженные утечки пойманы все: найденные точки 3027/3027, вычисленные числа шага 4198/4198, сырой «Шаг» с ответом 777/777;
  22 способа обхода (штрихи, двойники, числительные…) — все пойманы, хорошие реплики — пропущены.
- Линия связи: X′ и X″ на одной вертикали у всех 1473 пар во всех 150 вариантах начерта; о неоткрытых точках скрыто 3127/3127.
- Инжа: утверждения сверены с базой «каждая линия» на всех 761 элементе.
- Лестница: 19 сценариев §4.1.

```
node tools/tutor-make.js          # пошаговые данные (начерт — через браузер)

node tests/tutor.js
```

## Что остаётся за пределами ядра

Парсер свободной реплики ученика моделью (intent + утверждения в формате `claim` — ядро их проверяет), облачная функция с
моделью, модель ученика (Эло/BKT, уже есть в подготовке) в кабинете. Это четвёртый шаг плана.
