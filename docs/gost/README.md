# Тексты стандартов для сверки реестра ЕСКД

Сюда кладутся тексты ГОСТ, по которым сверяется реестр норм сайта (`window.ESKD` в `index.html`).
Проверка — `node tests/eskd.js` (её же запускает `tests/run.js`).

## Как положить стандарт

- Один файл — один стандарт, в имени — его номер: `2.303.txt`, `ГОСТ 2.303-68.pdf`, `ГОСТ Р 2.104-2023.pdf`.
- `.txt` читается как есть. `.pdf` переводится в текст программой `pdftotext` (пакет poppler-utils). Скан без текстового слоя
  не прочитается — для него нужен `.txt` рядом (распознанный текст).
- Номера, которые ждёт реестр: 2.301, 2.302, 2.303, 2.304, 2.305, 2.306, 2.307, 2.316, 2.104.

## Что происходит после этого

Для каждой нормы реестра проверка ищет её цитату (`q`) в тексте стандарта дословно, без учёта регистра, пробелов, вида тире
и многоточия. Отчёт делит нормы на три группы:

| Группа | Что значит | Что делать |
|---|---|---|
| сверено с текстом | норма помечена `ver:'text'`, цитата найдена, числа нормы стоят в цитате | ничего |
| можно отметить «text» | цитата найдена, но норма ещё помечена `web` или `mem` | поставить `ver:'text'` |
| не найдено | цитаты в тексте нет | открыть стандарт, переписать `q` дословно, поправить `v` и `p`, если они другие; затем `ver:'text'` |

Норма с `ver:'text'` с этого момента защищена: если цитату или число в реестре изменят так, что они разойдутся с текстом
стандарта, проверка упадёт. Значение в реестре меняется в одном месте — листы, нормоконтроль и теория пересчитываются сами.

Правила с `d:'МУ'` — методические указания кафедры, а не пункты ГОСТ. Их не с чем сверять в этой папке; на сайте они
подписаны «методические указания кафедры».
