# «Спроси автора» — вопросы и ответы внутри сайта

Ученик пишет вопрос на сайте, автор отвечает в пульте, ответ приходит туда же. Telegram в этом не участвует.

## Как это выглядит

| Кто | Где | Что |
|---|---|---|
| Ученик | кнопка **«Спросить»** в шапке (на каждой странице), строка «Застрял? Спроси автора» на главной, «Задать вопрос автору» внизу и под разборами | `#/ask`: одна форма «Что не получается?» + фото чертежа. Форма помнит, с какой страницы спросили («Про: ДЗ №3 · вариант 8»). |
| Ученик | `#/ask` → «Мои вопросы», `#/ask/<id>` | переписка: свои сообщения справа, ответы автора слева; можно уточнить. Новый ответ — число на кнопке «Спросить» и всплывающая карточка «Автор ответил», на какой бы странице ни был. |
| Автор | пульт `me/`, вкладка **«Вопросы»** (Alt 5) | слева — «Ждут ответа» / «Все», справа — переписка: кто (имя, группа, вариант), с какой страницы (ссылка откроет её во вкладке «Сайт»), фото; ответ (Ctrl+Enter), фото к ответу, «Закрыть вопрос». Число ждущих — на вкладке и в заголовке окна, проверка раз в 30 с. |

Писать может только вошедший. Гость пишет вопрос, жмёт «Войти и отправить» → вход в кабинете (Яндекс ID или почта) →
возврат на `#/ask` → вопрос уходит сам (черновик `lk_ask_draft`, адрес возврата `lk_ret`).

## Устройство

- Страница — `lk/ask.js` (подключён в `index.html` после `lk/config.js`); `index.html` рисует только `<div data-ask-root>` и
  `<div data-ask-home>`, модуль заполняет их сам. Старый адрес `#/live` открывает ту же страницу; `#/live/show` — режим эфира, как был.
- Пульт — `me/hub.js` (раздел «вопросы учеников»), сессия кабинета `lk_tok` с ролью админа.
- Сервер — API кабинета (`server/lib/app.js`, раздел «вопросы автору»), таблицы `club_ask` (ветки) и `club_askimg` (фото).
  Таблицы создаёт развёртывание (`server/tools/deploy.js`, Actions «Личный кабинет — развёртывание»).

| Запрос | Кто | |
|---|---|---|
| `GET /api/ask` | вошедший | свои ветки, `unread` — новых ответов |
| `GET /api/ask/t?id=` | хозяин ветки | переписка; отмечает прочитанным |
| `POST /api/ask` `{text, img?, src, where}` | вошедший | новый вопрос (12 в час) |
| `POST /api/ask/msg` `{id, text, img?}` | хозяин ветки | уточнение (60 в час); закрытый вопрос открывается снова |
| `GET /api/ask/img?id=` | хозяин ветки или админ | фото |
| `GET /api/admin/ask` | админ | все ветки, `waiting` — ждут ответа |
| `GET /api/admin/ask/t?id=` · `POST /api/admin/ask/msg` · `POST /api/admin/ask/close` | админ | переписка · ответ · закрыть / открыть |

- Фото сжимает браузер (до 1400 px, JPEG < 200 КБ); сервер принимает только `data:image/jpeg|webp|png`, до 280 КБ.
- Текст — до 3000 знаков, в ветке — до 80 сообщений. Вопросы входят в «Скачать мои данные» и удаляются вместе с аккаунтом.
- Сайту разрешено ходить в API: в CSP `index.html` — `connect-src https://*.apigw.yandexcloud.net`.

Проверка: `node --test server/test/ask.test.js` (сервер), `node tests/ask.js` (сайт + пульт в браузере, входит в `node tests/run.js`).
