| Справочно: шаги в обратном и случайном порядке | 356 | 5 — замечания верные: размер нарисован раньше точки, которую он измеряет, штриховая — раньше закрывающей грани |

**Найдено и исправлено в самой проверке:**
1. Вердикт видимости зависел от порядка элементов на чертеже (замер «в другом порядке» дал 2–3 ложных замечания в № 46).
   Причина — ошибка приоритета операторов в `has(A,B)`: тип линии проверялся только для одного направления стороны, и треугольник
   признавался плоскостью или нет в зависимости от порядка вершин. Исправлено; заодно положение подписи — центр всех её вхождений,
   вершины многоугольника — все подписанные точки в этом месте, вердикт — только если верен для каждой прямой, на проекции которой
   лежит отрезок. После исправления — 0 из 267.
2. Разбор HTML во всех проверках принимал знак «<» в тексте («y<sub>B</sub> < 0») за начало тега и выбрасывал текст до следующего «>»:
   утверждения в этом куске не проверялись вовсе (в `geometry.js`, `oracle.js`, `theory.js`, `provenance.js` и др.).
   Теперь удаляются только настоящие теги. Открывшийся текст проверен: два срабатывания шаблонов теории оказались неточностью шаблонов
   (верный текст «по сравнению с I четвертью: это III четверть (y < 0, z < 0)»), шаблоны уточнены и по-прежнему ловят неверные фразы.

## Этап 3. Выжившие мутанты кода — разбор

`node tests/adequacy.js --per=2 --seed=5` теперь разбирает каждого выжившего мутанта:

- **данные** — опечатка в числе, которое генератор вариантов меняет как исходные данные. Это та же программа на других данных;
  на 30 случайных наборах данных задача проходит проверку (`random-run`), значит, построение верно и для этих. Эквивалентный
  по построению; ошибку «перенесли не те данные из тетради» ловит только сверка с фото тетради.
- **оформление** — все точки, прямые, подписи и тексты те же, другие только длины отрезков (вылет вспомогательной линии).
  Эквивалентный.
- **условие** — изменился чертёж «дано» (сама задача), а число не из данных генератора. Неясно: нужна сверка с тетрадью.
- **пропуск** — построение изменилось, а проверка молчит. Реально пропущенный.

## Этап 5. Полнота

- **Ответ по условию:** 125 из 130 пунктов (было 123). Добавлены 68 в и 77 в. Остались 73 в, 74 б, 74 в, 89 б, 89 в —
  пересечения поверхностей (наклонный конус и цилиндр, эллиптический цилиндр, эллипсоид, два конуса): их параметры на чертеже
  не подписаны, а оракул по замыслу читает данные только с чертежа. Для них нужен протокол сертифицированного эпюра
  (`tests/certified`) или подписи параметров на чертеже.
- **Точное исполнение в рациональных числах:** по-прежнему № 46 и № 47. Для каждой следующей задачи нужен протокол шагов
  (`tests/certified/t46.js` — образец); для задач с окружностями и кривыми (№ 61–89) рациональная арифметика неприменима:
  точки пересечения с окружностью иррациональны. Кандидаты из задач на прямые и плоскости (№ 9–60) — следующий шаг.

- Эксперимент на студентах (эффект обучения) — нужен преподаватель и группы, кодом не решается. Аналитика готова к пилоту.
