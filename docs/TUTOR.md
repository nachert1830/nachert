# ИИ-наставник: объясняет на самом чертеже

Наставник («Ассистент Андрея») учит пространственному мышлению прямо на чертеже. Он подсвечивает линии, проводит
линию связи, показывает шаг по частям и открывает 3D, а говорит одну-две фразы и задаёт вопрос.

**Наставник не может ошибиться в геометрии.** Модель только говорит. Всё, что она утверждает о чертеже, сначала проверяет
геометрическое ядро сайта по чертежу, который вычислил решатель задачи. Неверное до студента не доходит.

Постановка задачи — [`AI-TUTOR-PROMPT.md`](AI-TUTOR-PROMPT.md).

## Как это устроено

```
Студент: «Не понимаю» · вопрос · голос · касание чертежа в «Решаю сам»
   ↓
Шторка под чертежом (kernel/tutor.js) ── без сети: лестница подсказок ядра, сразу
   ↓ вопрос (если студент вошёл и согласился)
/api/tutor (server/lib/tutor.js) → Claude: инструменты verify и reply
   ↓ каждое утверждение и каждое действие
Ядро (kernel/tutor-core.js, один файл для браузера и сервера)  ← истина
   ↓ прошло проверку
Чертёж: подсветка, линия связи, часть построения, шаг по частям, 3D  +  одна фраза в шторке
```

| Файл | Что делает |
|---|---|
| `kernel/tutor-core.js` | **Ядро наставника.** `build(part, k)` — снимок шага: точки, подписанные линии, группы построения (посредник и всё, что от него, — по цвету `col`), текст шага и лесенка решателя (`hint`, `principle`, `step`, `full`, `check`). `verify` — отношения на чертеже. `reply` — проверка ответа модели целиком. `ladder` — подсказки без модели. `tapCheck` — диагноз касания в «Решаю сам». Тот же файл подключён в `index.html` и `require`-ится сервером |
| `kernel/tutor.js` | **Шторка** в плеере разбора (`PLAYER`): кнопка «Не понимаю» на каждом шаге, в «Смотрю» и в «Решаю сам». Рисует ответ на чертеже тем же движком `DRAW`, в той же рамке. Голос — браузерное распознавание и синтез речи (ru-RU). Модель знаний студента |
| `server/lib/tutor.js` | Модель на сервере: родной Messages API Anthropic через ProxyAPI, инструменты, кэш промпта, лимиты, цена |
| `server/lib/app.js` | `POST /api/tutor` — вошедший студент, согласие на зарубежную модель, лимит в день, бюджет в день |
| `tests/tutor.js`, `tests/tutor-run.js`, `server/test/tutor.test.js` | Проверки (ниже) |
| `server/tools/tutor-eval.js` | Оценка на настоящей модели: набор вопросов с ловушками, метрики, цена |

### Ядро: что оно знает и проверяет

Снимок шага содержит только то, что вычислил решатель: точки с координатами чертежа, подписанные прямые, группы
построения шага (посредник Σ₁ и его сечения, линии связи, результат), текст шага. Отношения, которые ядро проверяет:

| `rel` | Утверждение | Как проверяется |
|---|---|---|
| `same_link` | A″ и A′ на одной линии связи | одна вертикаль (⟂ оси x), допуск — 0,6 % размера чертежа |
| `on` | точка лежит на линии или на построении посредника | расстояние до отрезка, ломаной, окружности |
| `coincide` | проекции совпадают (конкурирующие) | расстояние |
| `higher` | A выше B в пространстве | по фронтальным проекциям: z больше |
| `closer` | A ближе к зрителю | по горизонтальным проекциям: y больше |
| `parallel`, `perp`, `parallel_x`, `perp_x` | ∥ и ⟂ прямых и оси x | угол, допуск 2° |
| `exists` | такая точка или линия есть | снимок |

Ответ модели проходит ещё два фильтра: в тексте нет ни одной подписи вида A″, 3′, h″, Σ₁, которой нет на чертеже или
в тексте решателя, а действия на чертеже ссылаются только на существующие элементы. В «Решаю сам», пока шаг не показан,
раскрыть построение нельзя. Модели координаты не отдаются: отношения она спрашивает у `verify`.

### Действия на чертеже

| Действие | Что видит студент |
|---|---|
| `highlight` | подсветка точек, прямых или целого посредника (своим цветом, со свечением) |
| `link` | линия связи через проекцию; вертикаль верна по определению |
| `segment` | временная линия между двумя построенными точками |
| `reveal` | часть построения шага из решения решателя |
| `replay` | шаг по частям: посредник за посредником, с подписью «2 / 5 · посредник Σ₂ → 3″, 3′» |
| `3d` | этот шаг в 3D (`TASK3D`); посредники и сечения того же цвета, что на эпюре |
| `goto` | переход к шагу |
| `tap` | «Отметь на чертеже, где будет 3′» |

### Лестница подсказок (без модели и без сети)

Кнопка «Не понимаю» срабатывает сразу, без сети: первая реакция — от ядра.

0. **Намёк** — вопрос из лесенки решателя (`hint`) и подсветка опор шага: подписанных точек, через которые проходят
   новые линии (их находит ядро). Если опор нет, подсвечивается посредник шага. В «Решаю сам» наставник просит отметить точку.
1. **Почему так** — принцип (`why` / `principle`).
2. **Покажи на чертеже** — шаг по частям, группа за группой.
3. **В пространстве** — 3D этого шага.
4. **Весь шаг** — текст и числа шага, вопрос «Проверь себя».

Без входа свободный вопрос переводит на следующую ступень, а слова «почему», «покажи», «3D», «весь» выбирают ступень сами.

### «Решаю сам»: отметь, где будет точка

Ядро выбирает проекцию этого шага, у которой уже построена вторая проекция (`pickTarget`). Студент касается чертежа.
Координаты касания переводятся в координаты чертежа, и ядро ставит диагноз:

- **верно** — точка в допуске;
- **мимо линии связи** — «3′ и 3″ — проекции одной точки, они на одной вертикали»; линия связи проводится на чертеже;
- **не на той линии** — по линии связи верно, но выше или ниже; подсвечивается линия или посредник, на котором точка ещё лежит.

Ошибка записывается в модель знаний (`link`, `belong`).

### Модель знаний

Хранится в `ST 'tu_model'` и синхронизируется с кабинетом вместе с остальным прогрессом. В ней лежат заблуждения
(`link` — линии связи, `hf` — горизонталь и фронталь, `axis` — не та ось, `visibility`, `mediator`, `belong`, `nv`,
`rotate`, `order`, `reading`), касания (верно / нет) и самая высокая ступень подсказки на каждом шаге. Заблуждение, которое
встретилось два раза, шторка показывает как «слабое место». Модель на сервере тоже называет заблуждение (`misconception`).

## Модель

- Через ProxyAPI (оплата в рублях, ключ `PROXYAPI_KEY` уже есть у сканера), родной Messages API Anthropic:
  `https://api.proxyapi.ru/anthropic/v1/messages`. Сервер без зависимостей, поэтому запрос идёт обычным `fetch`.
- **Наставник — Claude Opus 5.5** (`claude-opus-5-5`), рассуждение `effort: low`: ответ за 6–10 секунд. Короткий ответ
  студента на вопрос наставника обрабатывает **Claude Haiku 5.5**.
- Кэш промпта: инструкция и инструменты, затем снимок шага (`cache_control`). Следующие вопросы на том же шаге читают их из кэша.
- Цикл: модель может вызвать `verify`, ответ даёт через `reply`. Если ядро не пропустило ответ, модель получает ошибку
  («утверждение higher(A, B) НЕВЕРНО по чертежу») и исправляется: до 4 обращений. Не справилась — студент получает
  подсказку ядра и кнопку «Спросить автора».
- Сбой шлюза (5xx, 529) — одна повторная попытка.

Настройки (переменные функции): `TUTOR=off`, `TUTOR_MODEL`, `TUTOR_FAST_MODEL`, `TUTOR_EFFORT`, `TUTOR_DAILY`
(вопросов в день на студента, по умолчанию 40), `TUTOR_DAY_USD` (бюджет на всех в день, по умолчанию 15 $),
`TUTOR_URL`, `TUTOR_KEY`.

## Безопасность, данные, деньги

- Модель зарубежная: вопрос уходит только с галочкой согласия в шторке. Без согласия работает лестница ядра.
- Уходят только текст вопроса, последние реплики разговора и снимок шага задачи. Имени, группы и фото в запросе нет.
  Сервер не хранит ни вопрос, ни ответ; в журнал пишет модель, число обращений и цену.
- `/api/tutor` доступен только вошедшему студенту. Лимит — 40 вопросов в день на студента. Дневной бюджет на всех
  исчерпан → ответ 429 и запись в журнал ошибок (алерт), шторка продолжает подсказками ядра.
- «Реши мне всё»: инструкция запрещает выдавать лист целиком, в «Решаю сам» ядро запрещает раскрывать шаг.
- Голос распознаёт и озвучивает браузер; на сервер уходит только распознанный текст.
