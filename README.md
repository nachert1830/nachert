# Начерт

Начертательная геометрия по шагам: решённая рабочая тетрадь, подготовка к РК, разборы ДЗ и интерактивная 3D-модель с эпюром.
Каждый чертёж — вычисленное построение, и каждое изменение сайта проходит автоматическую проверку (`tests/`, описание — `tests/README.md`).
На каждом шаге есть кнопка «Не понимаю»: ИИ-наставник объясняет прямо на чертеже — подсвечивает, достраивает, показывает шаг по частям и в 3D. Каждое его утверждение о геометрии до показа проверяет ядро сайта (`docs/TUTOR.md`).

Авторский учебный проект. Автор — Андрей Матханов. Сайт бесплатный и остаётся бесплатным; онлайн-занятия, которые ведёт автор, — его отдельная личная деятельность и к сайту не относятся.
Условия задач, теория и методика — по учебным изданиям МГТУ им. Н.Э. Баумана (список источников — на странице «О проекте»).
Решения, чертежи, пояснения и код подготовлены для этого сайта.

Сайт — один файл `index.html`, работает без сборки, установки и регистрации (почему так и как устроен — `docs/ARCHITECTURE.md`).

Цифры надёжности проверки с привязкой к версии кода — `docs/THESIS.md` (сырые данные — `docs/thesis.json`).

Шрифты (Golos Text, Geologica, IBM Plex Mono, Liberation Serif Italic) лежат в папке `fonts/`, лицензия SIL Open Font License 1.1; подписи чертежей — osifont (наклонный чертёжный шрифт по ISO 3098 / ГОСТ 2.304 тип Б, GPL с исключением для шрифтов, `fonts/osifont-LICENSE.txt`).
