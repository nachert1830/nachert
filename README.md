# Начерт

Начертательная геометрия по шагам: решённая рабочая тетрадь, подготовка к РК, разборы ДЗ и интерактивная 3D-модель с эпюром.
Каждый чертёж — вычисленное построение, и каждое изменение сайта проходит автоматическую проверку (`tests/`, описание — `tests/README.md`).

Авторский некоммерческий учебный проект. Автор — Андрей Матханов.
Условия задач, теория и методика — по учебным изданиям МГТУ им. Н.Э. Баумана (список источников — на странице «О проекте»).
Решения, чертежи, пояснения и код подготовлены для этого сайта.

Сайт — один файл `index.html`, работает без сборки, установки и регистрации (почему так и как устроен — `docs/ARCHITECTURE.md`).
Изменения сначала публикуются в закрытой тестовой версии из ветки `stage`, потом на nachert1830.ru (`docs/STAGE.md`).

Цифры надёжности проверки с привязкой к версии кода — `docs/THESIS.md` (сырые данные — `docs/thesis.json`).

Шрифты (Golos Text, Geologica, IBM Plex Mono) лежат в папке `fonts/`, лицензия SIL Open Font License 1.1.
